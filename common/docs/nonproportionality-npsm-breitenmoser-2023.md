## 1. Что это за работа и зачем она нам

Задача авторов: получить параметры модели непропорциональности светового выхода
**для своего конкретного экземпляра детектора**, не имея доступа к специальным
установкам (комптоновские совпадения, K-dip-спектроскопия, электронный пучок).

Их решение: параметры модели восстанавливаются **по сдвигу комптоновского края
в собственном гамма-спектре** прибора — байесовским обращением через
машинно-обученный суррогат МК-модели.

Для нас это бьёт прямо в **дыру 10 нашей методики**
(`detectors/RadiaCode-103/docs/method-plan.md`, R.6.4):
«разброс параметров между образцами больше температурного, концентрация Tl наших
кристаллов неизвестна». Работа даёт способ не брать чужие табличные параметры,
а измерить свои — прибором, который уже есть.

**Соавтор Cerutti — из группы FLUKA** (CERN). Расчёты сделаны на FLUKA 4.2.1,
не на Geant4. Это не мешает переносу: механизм внедрения модели одинаков
(взвешивание энерговыделения на шаге), различаются только имена пользовательских
подпрограмм.

## 2. Постановка эксперимента (стр. 2, 8)

| Параметр | Значение |
|---|---|
| Детектор | четыре призматических кристалла NaI(Tl) 10,2 × 10,2 × 40,6 см, раздельный съём |
| Каналов / диапазон | 1024 канала, ~30–3000 кэВ |
| Источники | ⁵⁷Co, ⁶⁰Co, ⁸⁸Y, ¹⁰⁹Cd, ¹³³Ba, ¹³⁷Cs, ¹⁵²Eu (Eckert & Ziegler) |
| Годятся для края | **только ⁶⁰Co, ⁸⁸Y, ¹³⁷Cs** — у остальных край забит пиками полного поглощения и их континуумами |
| Геометрия | источник на штативе, 1 м до передней грани, по центральной оси |
| Условия | воздух 18,8(4) °C, влажность 42(3) %, давление 982(5) гПа — **логировались** |
| Обращение выполнено по | ⁶⁰Co, A = 3,08(5)·10⁵ Бк; ⁸⁸Y и ¹³⁷Cs оставлены на проверку |

**Существенная деталь постановки:** обращение ведётся по **нижнему** краю ⁶⁰Co
(963,419(3) кэВ), потому что верхний (1118,101(4) кэВ) забит пиком 1173,228(3) кэВ.

Область края задана формулой (стр. 8); форма ниже **сверена по вёрстке**:

```
D_E := { E : E_CE − 3·σ_tot(E_CE) ≤ E ≤ E_FEP − 2·σ_tot(E_FEP) }
```

то есть от «три сигмы ниже теоретического края» до «две сигмы ниже пика».
Положение самого края — по классической формуле комптоновского рассеяния,
без доплеровского уширения и оболочечных эффектов (ур. 2, стр. 8):

```
E_CE = E_FEP · [ 1 − 1/(1 + 2·E_FEP/(m_e·c²)) ]
```

Чувствительность результата к выбору границ `D_E` проверена отдельно: в пределах
погрешностей результат к малым сдвигам границ **нечувствителен** (Supplementary Table S3).

**Ур. (2) проверено численно, а не переписано.** Подставлены пять пар «линия → край»,
приведённых в подписи к Fig. 4, при `m_e·c² = 510,99895 кэВ`:

| E_FEP, кэВ | расчёт, кэВ | в статье, кэВ | расхождение |
|---|---|---|---|
| 661,657 | 477,334 | 477,334 | 0,0000 |
| 898,042 | 699,133 | 699,133 | 0,0005 |
| 1173,228 | 963,420 | 963,419 | 0,0005 |
| 1332,492 | 1118,101 | 1118,101 | 0,0000 |
| 1836,063 | 1611,775 | 1611,770 | 0,0046 |

Сходится до долей эВ (расхождения — округление в статье).

Сверка **проверена на способность краснеть** (#SA-3), иначе совпадение ничего бы не
значило: убранный множитель 2 даёт промах 175 кэВ; перевёрнутый знак в знаменателе —
601 кэВ; сдвиг массы электрона на 0,1 % (511,5 вместо 510,999) — 0,19 кэВ, что при
пороге 0,01 кэВ тоже красное. То есть сверка ловит и грубую ошибку, и тонкую.

## 3. Модель, которую они калибруют, — та же Payne, что и у нас (стр. 2)

Световой выход как функция удельных потерь (их ур. 1). Форма **сверена по вёрстке PDF**
(стр. 2, растр области формулы при 6-кратном увеличении), а не восстановлена из
извлечённого текста:

```
                1 − η_e/h · exp[ − (dE/ds)/(dE/ds|Ons) · exp( − (dE/ds|Trap)/(dE/ds) ) ]
L(dE/ds)  ∝  ───────────────────────────────────────────────────────────────────────────
                                  1 + (dE/ds)/(dE/ds|Birks)
```

✅ **Форма подтверждена ВТОРЫМ, независимым источником** (05.09, после получения
дополнительных материалов): псевдокод `Algorithm S1` на стр. S47 дополнительных
материалов содержит ту же формулу строкой 15, включая вложенность экспонент и
перевёрнутую дробь в члене захвата. Два независимых предъявления — растр основной
статьи и псевдокод приложения — совпали. См. раздел 6a.

⚠ **Две ловушки этой формулы, обе поймались при сверке** (первая запись разбора,
сделанная по извлечённому тексту, содержала обе ошибки):

1. **Экспоненты ВЛОЖЕННЫЕ, а не перемноженные.** Внутренняя экспонента стоит
   множителем в показателе внешней. Запись вида `exp(A)·exp(B)` — неверна.
2. **Дроби в двух экспонентах перевёрнуты друг относительно друга.** В члене
   Онзагера параметр в **знаменателе**: `(dE/ds)/(dE/ds|Ons)`. В члене захвата
   параметр в **числителе**: `(dE/ds|Trap)/(dE/ds)`.

Вложенная форма — не типографская случайность, она выражает физику, названную в
тексте (стр. 2): захват носителей работает **экранирующим множителем на член
Онзагера**. Перемножение экспонент дало бы два независимых механизма, чего авторы
явно не утверждают.

Такая ошибка не дала бы ни предупреждения, ни абсурдного числа — только тихо
смещённый спектр. Извлечение текста из PDF расклеивает двухэтажные дроби, и
восстановленный порядок читается правдоподобно, но неверно.

Четыре параметра:

| Параметр | Физический смысл |
|---|---|
| `η_e/h` | доля носителей, рождённых как пары электрон-дырка на этапе термализации |
| `dE/ds\|Ons` | тормозная способность механизма Онзагера (превращение пар в экситоны) |
| `dE/ds\|Trap` | захват пар на точечных дефектах |
| `dE/ds\|Birks` | экситон-экситонная аннигиляция (механизм Биркса) |

**Важное для реализации утверждение авторов (стр. 2):** Онзагер и захват связаны
**нелинейно** (захват работает как экранирование члена Онзагера), а механизм Биркса
от них **независим**. То есть Биркс можно подгонять отдельно — это оправдывает наш
поэтапный план #BIRKS-1/#BIRKS-2.

Первые два звена цепочки (взаимодействие излучения и e⁻–e⁻ релаксация) считает
сам МК-код; модель Payne подхватывает с этапа рождения и переноса носителей.

### Разброс между четырьмя кристаллами ОДНОГО прибора (Table S2, стр. S43)

Получено 05.09 из дополнительных материалов. Это сильнее того, что сказано в
основном тексте, и для нас — центральный результат работы:

| | кристалл 1 | кристалл 2 | кристалл 3 | кристалл 4 | размах |
|---|---|---|---|---|---|
| `dE/ds\|Birks`, МэВ/см | 317 | **415** | 284 | **254** | **1,63×** |
| 95 % интервал | [287, 349] | [393, 436] | [247, 319] | [223, 288] | — |
| `dE/ds\|Trap`, МэВ/см | 13,3 | 14,1 | 15,0 | 13,7 | 1,13× |
| `η_e/h` | 0,605 | 0,594 | 0,575 | 0,575 | 1,05× |

**Доверительные интервалы по Бирксу у кристаллов 2 и 4 не перекрываются**
([393, 436] против [223, 288]) — это измеренное различие, а не разброс подгонки.

Практический вывод, которого нет в тексте статьи, но который следует из таблицы:
**параметры ведут себя по-разному.**

- `η_e/h` устойчив между образцами (размах 5 %) — табличное значение для него
  сгодится как первое приближение;
- `dE/ds|Birks` **не устойчив** (размах в 1,6 раза внутри одной поставки) —
  для него табличное значение бессмысленно, он обязателен к калибровке по своему
  экземпляру.

Это ранжирует нашу работу: если калибровать удастся только один параметр, калибровать
надо **Биркса**. Заметим противоречие, которое надо держать в голове: по
чувствительности края сильнее всего влияет `η_e/h` (раздел 5), а по межэкземплярному
разбросу хуже всего ведёт себя `Birks`. То есть край лучше всего *видит* тот параметр,
который и так стабилен, — это ограничение метода, авторами прямо не отмеченное.

### Что это значит для нас — вывод, ради которого стоило читать

Расхождение с табличными значениями **статистически значимо**, и авторы прямо
пишут (стр. 6): найдены значимые различия и **между четырьмя кристаллами одного и
того же прибора**, купленными вместе (Supplementary Table S2). Их формулировка:
это подтверждает результаты Hull и др. и «подчёркивает критичность калибровки
модели для каждой отдельной детекторной системы».

Практический перевод: **брать табличные параметры Payne для наших кристаллов и
считать результат откалиброванным — нельзя.** Промах по `Birks` в 1,7 раза —
это не поправка второго порядка. Дыра 10 методики этой работой не закрывается,
а **подтверждается количественно**: у нас теперь есть измеренная величина разброса
между образцами, а не предположение о нём.

## 5. Как параметр влияет на спектр (стр. 4, 6)

Направления сдвига комптоновского края (**в сторону меньших энергий**):

| Изменение параметра | Край |
|---|---|
| `dE/ds\|Birks` ↑ | сдвиг вниз |
| `η_e/h` ↑ | сдвиг вниз |
| `dE/ds\|Trap` ↓ | сдвиг вниз |

Чувствительность (полные индексы Соболя, по всей области края):

```
S_T(η_e/h)  >  S_T(dE/ds|Birks)  >  S_T(dE/ds|Trap)
```

То есть **сильнее всего край двигает доля свободных носителей `η_e/h`**, а не Биркс.

⚠ Оговорка самих авторов (стр. 6): ранжирование по чувствительности «следует
толковать осторожно», потому что именно `dE/ds|Trap` сильно зависит от температуры
и от радиационного повреждения кристалла. Малая чувствительность края к `Trap`
не означает, что `Trap` неважен, — она означает, что **по краю его плохо видно**,
и температурную зависимость по одному краю не восстановить.

## 6. Метод внедрения в МК — прямо применимо к нашему коду (стр. 8)

Формулировка авторов: они **взвешивают каждое отдельное событие энерговыделения
в сцинтилляторе — точечное или вдоль трека заряженной частицы — величиной
светового выхода из ур. (1)**. В FLUKA это сделано пользовательской подпрограммой
`comscw` (алгоритм — Supplementary Algorithm S1); события набираются
поштучно через `usreou` + карту `detect`.

**Соответствие в нашем контуре:** это ровно `Rc103FieldSteppingAction.cc` —
вес шага вместо голого `GetTotalEnergyDeposit()`. Значит план #BIRKS-1/#BIRKS-2
методически совпадает с рецензированной работой, а не является нашей выдумкой.

Достоинство подхода, которое авторы отмечают отдельно (стр. 7): модель считается
**на лету внутри МК**, а не постобработкой с офлайновой свёрткой, как в более
ранних работах. Это экономит счёт и, главное, снимает необходимость хранить
огромные файлы с данными по вторичным частицам. Наш конвейер устроен так же.

Настройки их расчёта, для сверки с нашей таблицей #CFG-1:

| Что | У них (FLUKA) | Замечание для нас |
|---|---|---|
| Набор физики | `precisio` — полностью связанный перенос γ/e⁻/e⁺ | аналог нашего `option4` |
| Порог переноса в кристалле | **1 кэВ** | и в ближайших к кристаллу деталях (отражатель, окно, корпус) |
| Порог в остальной модели | 10 кэВ | ради скорости |
| Явно включено | рождение и перенос вторичных электронов, флуктуации Ландау, рентгеновская флуоресценция | авторы называют всё это **существенным** для непропорциональности |
| Первичных на прогон | 10⁷ | даёт σ_stat < 1 % в каждом канале |

Строка про флуоресценцию — независимое подтверждение нашего решения по #CFG-2
(`deex=max`): те же процессы названы существенными именно для задачи
непропорциональности.

## 6a. ЭТАЛОННЫЙ АЛГОРИТМ (Supplementary, стр. S47) — прямое ТЗ на #BIRKS-1

Получен 05.09 вместе с дополнительными материалами. `Algorithm S1` — псевдокод
подпрограммы `COMSCW`, вызываемой при **каждом** событии энерговыделения в кристалле.
Авторы называют его упрощённой версией реально применённой.

```
1:  load EventID          ▷ {"continuous", "local"}
2:  load ParticleID
3:  load dE               ▷ выделенная энергия
4:  if EventID = "continuous" AND (ParticleID = "electron" OR "positron") then
5:      load ds           ▷ КРИВОЛИНЕЙНЫЙ путь частицы
6:      S = dE/ds         ▷ оценка тормозной способности
7:  else if EventID = "local" then
8:      load Ek           ▷ кинетическая энергия частицы
9:      if ParticleID = "electron"  then S = EDEDXT(Ek)   ▷ ВСТРОЕННАЯ таблица dE/dx
11:     else if ParticleID = "positron" then S = PDEDXT(Ek)
13:     end if
14: end if
15: dL = dE × L(S)        ▷ взвешивание по ур. (1)
```

### Три вещи, которых не было в основном тексте и которые меняют ТЗ

**1. Тормозная способность считается ДВУМЯ РАЗНЫМИ способами, и это не деталь.**
События делятся по порогу 1 кэВ:

| Тип события | Когда | Как берётся `S` |
|---|---|---|
| **continuous** | E > 1 кэВ; ионизационные потери размазаны вдоль шага | `S = dE/ds`, где `ds` — **криволинейный** путь |
| **local** | E < 1 кэВ; частица не переносится, энергия оставлена на месте (сюда же попадают продукты атомной деэкситации) | `S = EDEDXT(Ek)` — **встроенная таблица тормозной способности по кинетической энергии** |

Почему это критично для нас: у локального депозита длина шага стремится к нулю.
Наивное `edep / stepLength` в `SteppingAction` даст деление на ноль либо абсурдно
большое `S`, при котором знаменатель `1 + S/(dE/ds|Birks)` взлетает и световой выход
обнуляется. Дефект тихий: расчёт не падает, просто теряет свет на низкоэнергетичном
хвосте — ровно там, где непропорциональность сильнее всего.

**Соответствие в Geant4:** роль `EDEDXT`/`PDEDXT` играет
`G4EmCalculator::GetDEDX(Ek, particle, material)`. Это подлежит проверке ступенью
(−1) §33 — возможно, в контуре уже есть обёртка.

**2. Взвешиваются только электроны и позитроны.** Условие строки 4 явно ограничивает
тип частицы. Гамма-квант, выделивший энергию, сам по себе не взвешивается —
взвешивается порождённый им электрон. В `SteppingAction` это фильтр по
`G4Track::GetDefinition()`.

**3. Порог 1 кэВ — не настройка производительности, а граница двух ветвей алгоритма.**
В нашей таблице #CFG-1 порог продукции сейчас 0,05 мм, задан в единицах длины.

## 7. НАХОДКА, МЕНЯЮЩАЯ НАШ КОНВЕЙЕР: двойной учёт разрешения

Это самый ценный практический пункт разбора, и он не в результатах, а в Methods
(стр. 8–9, раздел про intrinsic resolution).

**Суть.** МК-расчёт, в который встроена модель непропорциональности,
**уже содержит внутри себя собственное (intrinsic) разрешение** — уширение,
порождённое самой непропорциональностью светового выхода. Оно возникает
автоматически, потому что разные траектории с одинаковой суммарной энергией
дают разный свет.

Поэтому размывать такой расчётный спектр **полной** измеренной шириной линии —
значит учесть непропорциональность дважды. Авторы (стр. 9) размывают
**адаптированной дисперсией**:

```
σ_broadening = √( σ²_tot − σ²_intr )
```

где `σ_tot` — полное измеренное разрешение, `σ_intr` — внутренний вклад,
полученный из самих МК-расчётов (серия моноэнергетических прогонов, затем
регрессия гауссовым процессом). Допущение — статистическая независимость
внутреннего вклада от переноса света, работы ФЭУ и тракта.

**Насколько велик вклад** (стр. 6–7, для их NaI(Tl)):

| Область энергий | σ²_intr / σ²_tot |
|---|---|
| E_γ ≳ 1500 кэВ | ≈ **0,35** (почти постоянно) |
| ≈ 440 кэВ | **≈ 0,42** — выраженный максимум |
| E_γ ≲ 440 кэВ | падает с уменьшением энергии |
| 28–60 кэВ | ломается K-краем иода 33,1694(4) кэВ |
| ≲ 10–30 кэВ | снова резкий рост |

Треть дисперсии, а у 440 кэВ — почти половина. Если это не вычесть, размытие
идёт множителем √(1/(1−0,35)) ≈ 1,24 — расчётные линии выйдут примерно на
**четверть шире** измеренных, и подгонка начнёт компенсировать это искажением
других параметров.

### Статус для нашего контура

Проверено фактом, не памятью: поиск по корню рабочего контура
(`grep -rln "gaus|smear|размыт|конволюц|convol" --include=*.py`) на 05.09.2026
не нашёл ни одного модуля спектрального размытия — только два частных скрипта
построения графиков. **Отдельного модуля размытия ещё нет**, он лишь запланирован
(`npr.py`, ревизия R.6 плана метода). То есть **ошибки в существующем коде нет,
находка поймана до реализации.** Это требование к спецификации модуля, а не правка.

**Требование к `npr.py` (вносится в R.6):** как только в расчёт включается
непропорциональность, размытие обязано вести дисперсию `√(σ²_tot − σ²_intr)`,
а не `σ_tot`. Пока `σ_intr` для наших кристаллов не оценена — это **допущение,
подлежащее строке в таблице #CFG-1**, а не молчаливый пропуск.

## 8. Проверка их модели и что осталось несходящимся (стр. 5–7)

Калибровка сделана по ⁶⁰Co, проверка — по ⁸⁸Y и ¹³⁷Cs (плюс ⁵⁷Co, ¹⁰⁹Cd, ¹³³Ba,
¹⁵²Eu в дополнительных материалах).

Результат: непропорциональная модель **статистически значимо лучше**
пропорциональной по всему спектру. Расхождения остались:
- у нижнего края области комптоновского края;
- между краем и пиком полного поглощения у ⁸⁸Y и ¹³⁷Cs;
- в комптоновском континууме ниже ~920 кэВ.

Авторы честно называют две возможные причины и не выбирают между ними:
систематика их массовой модели помещения либо **недостаточность самой модели
Payne**. Косвенно склоняются ко второй.

Отдельно подтверждено теорией и расчётом: **сдвиг края растёт с ростом энергии фотона**.

## 9. Границы применимости — что метод НЕ даёт

Названо самими авторами (стр. 7):

1. **Нужен разрешимый комптоновский край с достаточным отношением сигнал/шум.**
   Метод целиком стоит на измерении сдвига края. Сцинтилляторы со слабой
   непропорциональностью (LaBr₃(Ce), YAP(Ce)) дают малый сдвиг — калибровка
   затруднена, применимость не исследована.
2. **Край должен быть свободен от посторонних пиков.** Из семи источников
   у них годились только три — остальные забиты пиками полного поглощения.
3. `dE/ds|Ons` **не восстанавливается** — фиксируется по литературе (36,4 МэВ·см⁻¹).
   То есть свободных параметров три из четырёх.
4. Непропорциональные эффекты **усиливаются с ростом объёма кристалла**
   (стр. 2). Их кристаллы — 4,2 литра каждый.

### Перенос на наши приборы — трезвая оценка

| Прибор | Кристалл | Применимость метода |
|---|---|---|
| **Gamma-1S** | NaI(Tl), тот же материал | **Основной кандидат.** Материал совпадает с работой, есть с чем сверять. Нужен точечный источник с чистым краем (¹³⁷Cs) и контролируемая геометрия. |
| **RadiaCode-103** | CsI(Tl), ~1 см³ | **Метод в лоб не проходит.** Объём в тысячи раз меньше — край выражен слабо; на фоновом наборе в свинцовом домике (постановка оператора) края нет вовсе. Требуется отдельный прогон с источником, и даже тогда SNR под вопросом. |

Это ограничение согласуется с ранее высказанной оценкой оператора
(«для 103 нечего предложить, особенно на фоне в домике») — работа объясняет,
**почему** так: у метода есть физический порог по объёму кристалла и по наличию
края, а не только по нашей аккуратности.

Численные параметры их NaI(Tl) 4,2 л **напрямую в наш Gamma-1S не переносятся** —
это ровно та ошибка «взять чужие табличные», против которой написана статья.
Переносится **методика**, числа — только как порядок величины и как ориентир
диапазона априорных распределений.
