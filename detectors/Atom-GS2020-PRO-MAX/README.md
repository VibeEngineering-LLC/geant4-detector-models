# Atom GS2020 PRO MAX — NaI(Tl) Capescint Ø51×51

Разложение спектра образца Th-232 в сосуде Маринелли 1 л (известная активность 957 ± 57 Бк)
двумя независимыми методами Geant4 — по донорскому контракту страницы Гамма-1С (`detectors/Gamma-1S/web-th232`).

Живая страница: https://vibeengineering-llc.github.io/geant4-detector-models/gs2020-th232/

## Структура

| Папка | Содержимое |
|---|---|
| `analysis/` | подгонки (метод 1 — МК-шаблоны звеньев, метод 2 — сетка Geant4 × библиотека линий), калибровка (`cal/`), конфиги библиотек (`configs/`) |
| `geometry/` | `GS2020_Capescint51x51.gdml` — модель ПРИБОРА отдельно (корпус, кристалл NaI(Tl) Ø51×51, без пробы); `GS2020_marinelli_th232.gdml` — та же модель со вставленным сосудом Маринелли и Th-232; скрипты сборки (Blender → STL → GDML) |
| `geant4/run_marinelli/` | исходник приложения Geant4 (`main.cc`, `CMakeLists.txt`) — считает моноэнергетическую сетку отклика |
| `web-th232/src/` | исходник страницы (донорский `build_page.py` из `Gamma-1S/web-th232` подставляет CSS/JS донора и подменяет числа) |

## Переменные окружения

Пути к сырым измерениям и рабочим директориям расчётов машинно-специфичны, не входят в репозиторий и обязательны
(скрипты отказывают явной ошибкой, если переменная не установлена):

| Переменная | Смысл |
|---|---|
| `GS2020_REF` | папка с XML-спектрами прибора (образец, фон) |
| `GS2020_OUT` | рабочая директория расчётов Geant4 (шаблоны, JSON подгонок, логи) |
| `GS2020_EXE` | скомпилированный стенд `gs2020_marinelli.exe` |
| `GS2020_PAGE_WORK` | рабочая папка сборки страницы (необязательна, по умолчанию `<repo>/.work/gs2020-th232-page`) |
| `GS2020_DEVICE_GDML` / `GS2020_GDML_OUT` | вход/выход `geometry/gs2020_add_marinelli.py` |
| `GS2020_CALCHECK_XML` | проверяемый спектр для `analysis/gs2020_th232_calcheck.py` |
| `SPECTRAVIBE_ROOT` | внешний пакет чтения спектров (общий для всех детекторов репозитория, см. `detectors/Gamma-1S/analysis`) |

Пути внутри самого репозитория (донор `Gamma-1S/web-th232`, `common/py`) — относительные от `__file__`, работают
из любого расположения клона.

## Метод

Метод 1 — подгонка полного спектра суммой МК-шаблонов полного распада 8 звеньев ветви Th-232 (амплитуда одна на
всю ветвь, вековое равновесие). Метод 2 — моноэнергетическая сетка откликов Geant4 × библиотека выходов γ-линий
(переключаемая: 62 линии донорского порога 2 % либо 84 линии ENSDF порога 0,5 %) + 8 сумм-пиков каскадного
совпадения. K/L-рентген учтён в обоих методах всегда (#XR-1, `GEANT4\CLAUDE.md`) — в шаблонах метода 1 через
атомную деэкситацию (`fluo=1`), в библиотеке метода 2 отдельными строками (42 линии ENSDF на 8 звеньев).

Разрешение прибора — степенной закон ПШПВ(E) = k·E^p по линиям таблицы пиков самого прибора, калибровка каждого
спектра (образец, фон) — по своим реперам независимо (#CAL-2).

Подробности метода, инциденты и полная история расчёта — рабочий журнал контура (не публикуется).
