# Измеренные спектры Atom GS2020 PRO MAX

Спектры, на которых построены страницы детектора (Th-232, K-40, сушёная черника): сцинтилляционный спектрометр
NaI(Tl) Capescint Ø51×51, ПО Atom Spectra, сосуд Маринелли 1 л. Каждый спектр — один CSV-файл: шапка из строк
`# ключ: значение` и далее столбцы `channel,counts` (8192 канала). Кодировка UTF-8, перевод строки LF.
Это не сырые файлы прибора, а их числовое содержимое; контрольные суммы исходных файлов — в `manifest.json`.

## Как читать шкалу энергии

В шапке каждого файла две шкалы, обе — полиномы 4-й степени по номеру канала (нумерация с 0):
`E[кэВ] = c0 + c1·ch + c2·ch² + c3·ch³ + c4·ch⁴`.

1. `energy_scale_file_coeffs` — коэффициенты как записаны в исходном файле прибора (текст без изменений).
   **У всех файлов этой выкладки они одинаковы**, хотя усиление прибора между замерами менялось.
2. `page_scale_N` — шкала, по которой спектр размещён на странице: она получена подгонкой по пикам самого спектра
   (калибровка по реперным линиям, шкала — своя у каждого спектра) и не равна шкале файла. Для страницы
   отдельно указано, образец это или фон. Для фона на странице Th-232 и на страницах K-40 и черники применены разные
   полиномы, поэтому у файла фона две строки `page_scale`.

Шкалу каждого спектра нужно проверять по его пикам (K-40 1460,8; Tl-208 2614,5 кэВ и др.): по шкале файла
пик K-40 оказывается на 5–8 кэВ в стороне от истинной энергии (по шкалам страниц), на 2,6 МэВ — до 16 кэВ у KCl,
и сдвиг разный у разных замеров.
Чужую шкалу на другой спектр не переносить. Ширина пика (ПШПВ) и форма — свойства детектора, их берут из
референса (торий), а не из шкалы файла.

## Фон

Фон «Маринелли + вода» вычитается с множителем по живому времени, `k = live_time_пробы / live_time_фона`:
для Th-232 k = 0,48095, для рабочего спектра KCl k = 2,66142, для черники k = 0,60748. Это тот же фон для всех трёх
страниц. Прочие замеры фона (лабораторный фон без сосуда, промежуточные 11,7; 18,2 и 22 ч с водой) и ранний
спектр KCl 740 мл в выкладку не вошли: в данных всех трёх страниц фон — этот замер 33,2 ч (живое время 119423,3 с).

## Особенности

- **Последний канал (8191)** — накопитель импульсов выше диапазона (переполнение), его значение на порядки больше соседних;
  в спектр как пик он не входит и в подгонках не участвует.
- **Выровненная сумма KCl.** Между частями 1 и 2 пик K-40 сместился на +2,7 канала (0,09 %, по центроиду): сложение «в лоб»
  размазало бы пики. Часть 2 перебинована на шкалу энергии части 1 с сохранением суммы отсчётов (поэтому отсчёты дробные),
  затем сложена с частью 1; сумма отсчётов равна сумме накопленного спектра 88,3 ч. Побочный эффект перебиновки:
  переполнение части 2 (96918 отсчётов) оказалось в каналах 8179–8180 (около 4,76 МэВ по шкале файла), выше окна подгонок.
- **Часть 2 KCl** получена вычитанием по каналам: накопленный спектр 88,3 ч минус часть 1 (41,5 ч); живое время вычтено так же.
- В файле накопленного спектра 88,3 ч время начала записано позже, чем в файле части 1; значения даны как в файлах.
- Время начала и конца — по часам прибора, часовой пояс в файле не указан.

## Происхождение и воспроизведение

Atom GS2020 PRO MAX, ПО Atom Spectra. Выгрузка: `scripts/export_spectra_csv.py` в рабочем каталоге проекта
(читает исходные XML, пишет CSV и `manifest.json`: SHA-256 каждого CSV и исходного файла, сумма отсчётов, живое время).
Сверка CSV с исходниками и данными страниц — `scripts/verify_spectra_csv.py`.
