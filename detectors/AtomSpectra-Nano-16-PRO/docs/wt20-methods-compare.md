# Сравнение методик 1 и 2

Два способа собрать шаблон нуклида в контактной геометрии WT-20. Оба
считаются в одной и той же геометрии Geant4 (`geometry/ASN16Detector.cc`) и с
одним физлистом (`G4EmStandardPhysics_option4` + `G4DecayPhysics` +
`G4RadioactiveDecayPhysics`, атомная релаксация и Оже-каскад включены). Оба
дают шаблон, нормированный на один распад, и пригодны как отклик rᵢₖ в
матричном решении по методике ЛСРМ гл. 12. Оговорка о самой ссылке на гл. 12:
в оригинале шаблоны — экспериментальные, полученные из аттестованных
источников в геометрии проб, и совпадения входят в них по построению.
Требования гл. 12 к неопределённости шаблона на расчётные шаблоны
переносятся не автоматически — статистическая дисперсия там не единственная
и не главная (см. границы ниже).

## Суть

**Методика 1. Понуклидные Монте-Карло-шаблоны.** Разыгрывается распад целого
звена ряда, равномерно по объёму стержней. Первичная частица — ион; ядро
дочернего звена в основном состоянии убивается в `Stacking`, возбуждённое
трогается — именно его снятие даёт гамма-каскад. В шаблон одним прогоном
входят: одиночный отклик каждой линии каскада, внутренняя конверсия и
атомная релаксация после неё, бета и тормозное, флуоресценция окружающих
материалов. **Три оговорки:**

- Угловые корреляции каскадных гамма в Geant4 по умолчанию **выключены**
  (`fCorrelatedGamma=false`); референсный TccfCalc ЛСРМ (глава 17) их учитывает
  из спинов и мультипольностей переходов. Включаются командой
  `/process/had/deex/correlatedGamma true` — в наших макросах пока не стоит.
- Верность каскада упирается в данные распада Geant4. По уже сверенным
  выходам Ac-228 модель расходится с МАГАТЭ на 4–18 % отдельным линиям
  (задача №29), и эта систематика уходит в шаблон целиком.
- Сумм-область шаблона слабостатистична по построению: у Tl-208 выше
  2650 кэВ 31 отсчёт на 400 тыс. распадов, поэтому оценки собственно
  суммирования, снятые с готового шаблона, ограничены счётной статистикой,
  а не физикой.

**Методика 2. Матрица отклика × модель источника.** Разыгрываются
моноэнергетические кванты в тех же стержнях, шаг сетки сгущён у K-краёв
вольфрама и иода. Результат — матрица R(E → распределение энерговыделения).
Шаблон нуклида собирается уже без Geant4:

    rᵢₖ = Σ_линий y_kl · R(E_l → i)

по библиотечным выходам МАГАТЭ (гамма — `*_gammas.csv`, рентген — `*_xrays.csv`).
Каскад воспроизводится линия-в-линию: каждый переход, включая внутреннюю
конверсию и атомную релаксацию источника, лежит в библиотеке с абсолютным
выходом на распад и входит в свёртку. **Что теряется** — истинные
совпадения (COI): сумм-пики и потери из ППП, живущие на корреляции квантов
одного распада, а не на самих линиях.

## Плюсы и минусы

| | Методика 1 | Методика 2 |
|---|---|---|
| Одиночный отклик каждой линии каскада | входит в шаблон | воспроизводится линия-в-линию по библиотеке |
| Истинное суммирование каскада (COI, сумм-пики, потери из ППП) | входит переносом, но статистика в сумм-области ничтожна | ОТСУТСТВУЕТ, вводится отдельной поправкой (штатная практика поля: TccfCalc, EFFTRAN, TrueCoinc — одиночная ε × COI-факторы) |
| Угловые корреляции каскадных гамма | по умолчанию ВЫКЛЮЧЕНЫ; включаются командой | нет корреляций (линии независимы по построению) |
| Рентген атомной релаксации ИСТОЧНИКА | из переноса (данные распада Geant4) | из библиотеки эмиссии (`*_xrays.csv` в дереве проекта — покрытие полное) |
| Флуоресценция МАТЕРИАЛОВ (W стержней 57,98 / 59,32 и др.) | из переноса | из матрицы отклика — автоматически |
| Бета, тормозное, конверсионные электроны источника | из переноса | ОТСУТСТВУЮТ (моноэнергетические фотоны), значимо в мягкой области 60–150 кэВ |
| Обратное рассеяние, вылеты | в шаблоне | в матрице (одинаково у всех нуклидов) |
| Разложение отклика по каналам | не работает (первичная — ион, №42) | работает |
| Стоимость нового нуклида | отдельный прогон | ноль прогонов |
| Стоимость правки геометрии | пересчёт всех нуклидов | пересчёт одной матрицы |
| Статистика на слабых звеньях (Th-232, Ra-224) | почти пустой шаблон | не проблема, матрица не зависит от активности |
| Опора на внешние данные | схема распада данных Geant4 | библиотека эмиссии (МАГАТЭ / LNHB) |
| Прозрачность структур спектра | скрыта внутри шаблона | пики / комптон / рассеяние отдельными компонентами |
| Проверяемость каждой линии | нет | есть (выход × эффективность = площадь пика) |

## Область и границы применения

**Методика 1 применима**, когда: (а) физика распада хорошо описана данными
Geant4 и не является предметом исследования; (б) число нуклидов небольшое или
геометрия не меняется, так что стоимость прогонов терпима; (в) собственное
разложение отклика по каналам образования события не требуется.

**Границы методики 1**: угловые корреляции каскада по умолчанию выключены;
статистика собственно сумм-области ничтожна и не даёт снять COI с готового
шаблона; ошибка данных распада Geant4 (по Ac-228 уже измерена, S6/№29)
переносится в шаблон целиком; классификатор каналов (`*_chan.csv`) при
источнике-ионе вырождается (задача №42); pile-up (случайные совпадения) не
переносится в принципе — конкурирует с истинным суммированием выше 2700 кэВ
при загрузке 402 имп/с.

**Методика 2 применима**, когда: (а) нужно разделить структуры отклика
(пики / комптон / рассеяние / вылеты) для их независимого анализа; (б) один
измерительный тракт используется для многих нуклидов, и матрица считается
один раз; (в) требуется свобода в выборе библиотеки эмиссии (МАГАТЭ, LNHB,
уточнённые оценки), а не только та, что вшита в Geant4; (г) есть время на
плотную сетку у K-краёв — обязательно с узлами ПО ОБЕ СТОРОНЫ каждого края
(прецедент — S11: у K-края W в `xcom_wt20_alloy.csv` не было верхнего узла).

**Границы методики 2**: истинное суммирование каскада не воспроизводится
без отдельной поправки; электронный канал источника (бета, тормозное,
конверсионные электроны) не переносит совсем — в мягкой области 60–150 кэВ,
где сидит 3/4 текущей невязки, это значимо; при разложении на понуклидные
компоненты требует полной библиотеки эмиссии (для нашего дерева выполнено:
выкачка `rad_types=g` содержит и гамма-линии, и рентген атомной релаксации —
K/L-серии в хвосте файла; отдельная выкачка `rad_types=x` даёт те же линии с
теми же интенсивностями и служит только источником поля `shell` для снятия
дубля Kβ, складывать её с гамма-файлом нельзя); pile-up не переносится.

Масштаб суммирования для нашей геометрии — порядковая оценка из `Tl208.csv`:
вероятность любой регистрации за распад 3,94 % (15 755 из 400 000), средняя
полная эффективность на квант около 1,5–2 %; потеря из ППП пика 583,19 при
одновременном 2614,5 порядка ε_T(2614) ≈ 1,5 %; для пика 2614,5 суммарная
поправка от линий каскада 0,85·ε_T(583) + 0,23·ε_T(511) + … ≈ 2–2,5 %.
Итого — единицы процентов; меньше текущих систематик модели, больше целевой
точности активности.

## Типовые задачи

**Методика 1.**
- Активность источника в контактной или колодезной геометрии, когда каскад
  описан данными Geant4 и не является предметом исследования: WT-20 (эта
  работа), Гамма-1С с Маринелли, RadiaCode-103 с колодцем. Оговорка о
  колодце: у него COI максимально (Gilmore 2008: «worst of all when using a
  well detector»), и при смене библиотеки выходов COI-поправка требуется и
  там.
- Быстрая проверка методики измерения на источнике известной активности
  (слепой тест ASN16 на Cs-137, задача №3).
- Пересчёт при смене геометрии: масштаб пересчитывается ОДНОЙ ревизией
  прогонов, публикуется вместе со штампом `src_sha1`.

**Методика 2.**
- Библиотека шаблонов под разные нуклиды на ОДНОМ приборе и ОДНОЙ геометрии
  (парк RadiaCode, слепой тест по многим нуклидам, оперативная спектрометрия
  проб с меняющимся составом).
- Разложение отклика на структуры для сравнения с чужими способами обработки
  или для метки события в спектре (какой канал образования дал вклад в
  измеренный пик).
- Работа с уточнёнными библиотеками линий, отличными от данных Geant4:
  переоценки МАГАТЭ, LNHB, специальные оценки для рентгена.
- **COI-поправка без второй методики**: полная эффективность ε_T(E) в
  каждой энергии сетки достаётся суммированием столбца матрицы (число
  зарегистрированных на число разыгранных). Этого достаточно для поправок по
  Gilmore 2008, формулы 8.3–8.5, без построения понуклидного шаблона вовсе.

## Совмещённое использование

Обе методики применимы одновременно. Методика 2 даёт **пики и одиночный
отклик**, методика 1 — доступ к **суммированию каскада** как разность
понуклидного шаблона и свёртки матрицы с линиями. **Обязательное условие
корректности этой разности** — согласование выходов линия-к-линии ДО её
взятия: перевзвесить понуклидный шаблон на библиотечные выходы либо свёртку
на выходы Geant4. Иначе разность равна не только вкладу суммирования, но и
разнице библиотек. Для нашего дерева Δ библиотек на опорных линиях ветви A1
(Ac-228 338,32; 911,20; 968,97) сравнима с самим суммированием или больше:
модель эмитирует 338 на 17,8 % выше МАГАТЭ, 911 и 969 — на 3,7 и 4,0 %.

**Альтернатива совмещению** для COI-поправки: методика 2 самостоятельно
даёт ε_T(E) и ε_ppp(E), а поправки берутся по каноническим формулам
Gilmore 2008, гл. 8. Этот путь короче и не требует опоры на понуклидный
Монте-Карло-шаблон.

Согласие двух методик на одиночных пиках (после согласования выходов) —
независимая проверка модели.
