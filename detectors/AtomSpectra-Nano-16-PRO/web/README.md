# Интерактивная страница «Из чего складывается спектр»

Разбор функции отклика AtomSpectra Nano 16 PRO по каналам взаимодействия.
Данные — прогон сетки `spectra_resp50` (61 узел 30–3000 кэВ, 5·10⁵ историй на
узел) и матрица отклика из `../results/`.

## Что показывает

* **Полоса состава в шапке** — доли всех каналов на всех 61 узле сразу:
  видно, как фотоэффект уступает комптоновскому рассеянию, а выше порога
  1022 кэВ появляются каналы рождения пар.
* **Три вкладки-энергии** (180, 1480, 3000 кэВ) — отклик, разложенный по
  каналам. Каждый канал снимается флажком. Второй вид переводит те же данные
  в доли: какой канал преобладает в каждой точке шкалы энерговыделения.
* **Карта отклика** — вся матрица 61 × 320 с движком по строкам и
  переключателем приборного разрешения.
* Пояснения — во всплывающих окнах: по каналу (кнопка «?» в списке), по
  элементу спектра (кнопки под графиком или щелчок по штриховой линии), по
  методу, по сводке чисел.

## Сборка

```
python export_data.py            # прогон -> asn16_data.json
python build_page.py             # шаблон + данные -> dist/ и один файл
```

Выход:

| путь | назначение |
|---|---|
| `dist/index.html` + `dist/styles/` + `dist/scripts/` + `dist/data.js` | раздельные файлы, для статического хостинга |
| `asn16_response.html` | то же одним файлом, для площадок, принимающих один файл |

`dist/` и `asn16_data.json` в репозиторий не коммитятся: это производные,
пересобираются из исходников одной командой.

## Правила, встроенные в конвейер

Числа в прозе **не набираются руками**. В разметке стоят метки вида
`{{p photo 180}}`, значения подставляются при сборке из той же выгрузки, из
которой рисуются графики. Сборка отказывается собирать страницу, если:

* сумма каналов не сошлась с полным спектром узла до отсчёта;
* остаточный канал (сторож классификатора) населён;
* положение пика вылета по данным разошлось с формулой E₀ − 511 / E₀ − 1022
  больше чем на канал гистограммы;
* доля телесного угла в шапке прогона не отвечает объявленному конусу;
* сетка узлов неравномерна сверх единственного объявленного исключения;
* хоть одна подстановка не разрешилась;
* в тексте найдена доля в процентах, набранная цифрами;
* секрет-скан нашёл локальный путь, адрес почты или токен.

Проверки сделаны через `raise`, а не `assert`: под `python -O` инструкция
`assert` вырезается, и сторож молча исчез бы.

Свёртка с приборным разрешением, ширина канала отображения и нормировка на
квант в 4π скопированы дословно из `../analysis/draw_channels.py` и
`../analysis/response_matrix.py`, чтобы страница и штатные иллюстрации не
могли разойтись.

## Две величины, которые легко перепутать

«Ничего не вылетело из кристалла» — сумма трёх каналов без вылета. «В пике
полного поглощения» — счёт в окне ±1 кэВ вокруг энергии кванта. Вторая
величина меньше первой и расходится с ней тем сильнее, чем жёстче квант
(92,38 против 75,80 % на 180 кэВ; 9,86 против 6,20 % на 3000): часть
первичных теряет энергию в крышке и корпусе **до входа** в кристалл, и такое
событие идёт в канал без вылета, а в спектре ложится ниже пика.
Классификатор (`../geometry/main.cc`, `EventAct::Channel`) смотрит только на
вылет из кристалла и этих потерь не видит.

## Оформление

Стили и код вынесены отдельными файлами (`src/styles/`, `src/scripts/`):
правки палитры и типографики не задевают ни разметку, ни отрисовку. Цвета
каналов заданы в таблице стилей дважды — для светлой и тёмной темы: одна и
та же заливка не даёт нужного контраста и на белом, и на почти чёрном.
