## Лид из соседнего контура (не проверен)

В корпусе `gamma-spectrum-analysis` появились методические документы ЛСРМ
SpectraLineXX 1.7 с числовыми порогами. Применимо: порог площади пика
≥ 20 000 импульсов на устойчивость формы. Неприменимо без разбора: `χ²/ν ≈ 1`
у ЛСРМ — критерий подгонки ФОРМЫ ЛИНИИ, а в §5.1 отчёта тем же именем названа
мера согласия рядов нуклидов между собой — разные величины. Пороги
пересказаны, не прочитаны; перед использованием читать первоисточник.
