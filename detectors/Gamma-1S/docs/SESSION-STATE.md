   гарантия «отпечаток не отстанет от бинарника» проверена только на Ninja,

   квазиидентификатор, решение за оператором.
3. **Долг штампа**: результатных таблиц без объявления наблюдаемой стало на
   одну меньше (`ba133_sumpeak.csv` получил штамп в этой сессии); точный
   остаток по всему `results/` не пересчитан.
4. **Задача 95** — бюджет размерных неопределённостей; чувствительности 3,05 и
   0,89 %/мм производящего скрипта не имеют и подлежат пересчёту (используются
   в §5.4 с явной оговоркой, но вывод желательно подтвердить пересчётом).
5. **Обнаружено, не задача, а факт для памяти**: `p5_*` (спектры распада)
   регенерируются с новым случайным розыгрышем при каждом запуске драйвера —
   src_sha1 у них при этом НЕ меняется (код тот же), поэтому таблицы,
   производные от них (как `ba133_sumpeak.csv`), могут молча разойтись со
   свежим прогоном без сигнала от штампа провенанса. Штамп ловит устаревший
   КОД, не устаревший СЛУЧАЙНЫЙ РОЗЫГРЫШ. Стоит проверить, есть ли другие
   таблицы с той же уязвимостью (любая, читающая `p5_*` напрямую).

## Лид из соседнего контура (не проверен)

В корпусе `gamma-spectrum-analysis` появились методические документы ЛСРМ
SpectraLineXX 1.7 с числовыми порогами. Применимо: порог площади пика
≥ 20 000 импульсов на устойчивость формы — прямая проверка достаточности
статистики модельных пиков. Неприменимо без разбора: `χ²/ν ≈ 1` у ЛСРМ есть
критерий подгонки ФОРМЫ ЛИНИИ, а в §5.1 отчёта тем же именем названа мера
согласия рядов нуклидов между собой — разные величины. Пороги пересказаны, не
прочитаны; перед использованием читать первоисточник.
