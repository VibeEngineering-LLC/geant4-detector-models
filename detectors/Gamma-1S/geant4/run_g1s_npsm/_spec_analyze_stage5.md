# Спека: анализатор этапа 5 — расчёт Гамма-1С против измеренного спектра

Ты — генератор кода на Python 3.11. Верни ОДИН ПОЛНЫЙ файл, без пояснений вне
кода. Комментарии — по-русски. Формат:

```
=== FILE: analyze_stage5.py ===
<полный текст>
```

## Назначение

Сравнить расчётный спектр Гамма-1С (¹³⁷Cs, точечный источник 5 см) с
аттестованным измерением и ответить: даёт ли учёт непропорциональности
улучшение. Отрицательный ответ — законный результат, а не провал.

## Вход

```
python analyze_stage5.py --on <csv> --off <csv> --spe <path> [--json out.json]
```

- `--on` — прогон стенда с включённой моделью (`npsm_enabled=1`);
- `--off` — прогон с выключенной (`npsm_enabled=0`), то же зерно;
- `--spe` — измеренный файл LSRM `.spe`.

## Чтение расчётного CSV

Шапка `ключ,значение` до строки `bin_keV`; затем таблица
`bin_keV,count_edep,count_light` (шаг 1 кэВ). Из шапки нужны:
`energy_keV`, `npsm_enabled`, `n_events_processed`, `npsm_bad_s_count`,
`npsm_out_of_range_count`.

Если `npsm_enabled` прогона `--on` не равен 1, либо у `--off` не равен 0 —
громкая ошибка и возврат 3. Молча не продолжать.

Шкала энергий измеренного спектра — полином из `energy_cal`
(коэффициенты по возрастанию степени, канал → кэВ).

## Разрешение прибора

`ПШПВ(E) = -6.2914323508675 + 1.7442782325498*sqrt(E) + 0.0049483216398*E`, кэВ,
E в кэВ. Это `stored_fwhm_calibration` ЭТОГО ЖЕ файла; проверено: при
E = 661,658 даёт 41,850 против 41,85 в таблице пиков.
`sigma(E) = ПШПВ(E) / (2*sqrt(2*log(2)))`.

## Три варианта расчёта

Расчёт даёт спектр по СВЕТУ (`count_light`). Порядок:

1. **Калибровка света в энергию.** Найти пик полного поглощения в
   `count_light`, взяв бин максимума в области `[0.3*E0 ; 1.05*E0]`, где
   `E0 = energy_keV` из шапки; положение уточнить центром тяжести по бинам
   выше половины максимума. Коэффициент `k = E0 / положение_пика`.
   🔴 Калибровка умножает ШКАЛУ энергий, а не счёт отсчётов:
   `centers = [b * k for b in bin_centers]`. Умножать `count_light` на `k`
   ЗАПРЕЩЕНО — эта ошибка уже допускалась дважды в соседнем анализаторе.
2. **Размытие** — свёртка с гауссианой ПЕРЕМЕННОЙ ширины: для каждого бина
   `i` ширина берётся по его собственной энергии `sigma(centers[i])`,
   вклад раскладывается по соседям в пределах ±4σ. Нормировка ядра на
   единицу суммы, чтобы площадь сохранялась.
3. Три варианта:

| вариант | источник | множитель ширины |
|---|---|---|
| (а) | `--off` | 1,0 |
| (б) | `--on` | 1,0 |
| (в) | `--on` | **0,798** |

Множитель 0,798 = √(1 − 0,363): часть дисперсии уже внесена самой моделью,
и размывать полной шириной значит учесть разрешение дважды.
Вариант (б) — намеренно неверный, он и измеряет цену двойного учёта.

## Приведение к измерению — ОБЩАЯ СЕТКА

Завести общую сетку `grid = [50, 51, …, 1000]` (шаг 1 кэВ, длина 951).
**Индекс энергии E на этой сетке равен `int(E) - 50`** — все дальнейшие
операции сравнения идут ТОЛЬКО в этих индексах.

- расчётные варианты (а),(б),(в) интерполировать с их калиброванной шкалы
  `bin_centers * k` на `grid` (линейная интерполяция, вне области — ноль);
- измеренный спектр интерполировать с его полиномиальной шкалы
  (`energy_cal`, канал → кэВ) на тот же `grid`; счёт канала перед
  интерполяцией поделить на ширину канала в кэВ, иначе плотность отсчётов
  исказится переменным шагом.

🔴 Сравнивать спектры, лежащие на РАЗНЫХ шкалах, по одинаковым индексам
запрещено: расчёт после калибровки имеет шаг `k ≈ 2` кэВ, измерение — свой,
и совпадение индексов означало бы сравнение разных энергий.

Затем **нормировать каждый спектр на площадь его пика 662**: окно ±3·σ вокруг
661,658 кэВ по общей сетке, вычитая линейную подложку, проведённую по средним
из пяти бинов у каждого края окна. Абсолютная скорость счёта не сравнивается —
допущение Д-10.

## ПШПВ вариантов — ИЗМЕРЯЕТСЯ, а не берётся из формулы

🔴 Для каждого из трёх вариантов ПШПВ определяется **по самому свёрнутому
спектру** на общей сетке: найти максимум в окне ±60 кэВ вокруг 661,658,
вычесть подложку, затем найти левую и правую точки половины высоты с
ЛИНЕЙНОЙ ИНТЕРПОЛЯЦИЕЙ между соседними бинами; ПШПВ — их разность.

Подставлять сюда `ПШПВ(E)` из калибровочной формулы прибора **ЗАПРЕЩЕНО**:
эта формула — то, с чем мы сравниваем, и, взяв её, критерии Г-2 и Г-3 стали бы
тождеством. Так уже было сделано в первой генерации: все три варианта получили
одинаковую ширину, и проверка выродилась.

## Критерии — назначены ДО прогона, менять запрещено

| № | Критерий | Порог |
|---|---|---|
| Г-1 | положение пика 662 во всех трёх вариантах | расхождение с измеренным ≤ 10,5 кэВ (0,25·ПШПВ) |
| Г-2 | ПШПВ варианта (в) | 41,85 кэВ ± 5 % |
| Г-3 | ПШПВ варианта (б) | **строго шире** измеренной |
| Г-4 | невязка по континууму 200…450 кэВ | у (в) меньше, чем у (а), на величину БОЛЬШЕ суммарной статистической погрешности обоих |
| Г-5 | счётчики модели в обоих прогонах | `bad_s = 0` и `out_of_range = 0` |

Невязка считать как `χ² = Σ (расчёт − измерение)² / (σ²_расч + σ²_изм)` по
бинам полосы, где σ — корень из числа отсчётов до нормировки, пересчитанный
тем же коэффициентом нормировки. Печатать также приведённую невязку на
степень свободы.

**Г-4 — главный.** Если улучшения нет, это результат, а не провал: значит для
Гамма-1С в данной постановке учёт непропорциональности статистически не
различим. Так и написать.

## Вывод

1. Таблица: вариант, положение пика, ПШПВ, χ²/n по континууму.
2. Блок «КРИТЕРИИ» Г-1…Г-5: порог, факт, PASS/FAIL.
3. Блок «ТРЕБУЕТ ТОЛКОВАНИЯ» (печатать всегда): если в полосе континуума
   меньше 500 отсчётов; если ПШПВ (а) и (в) различаются меньше, чем на
   статистическую погрешность; если положение пика в (а) и (б) разошлось
   больше чем на 2 кэВ.
4. Итог `STAGE5_ACCEPTANCE=PASS|FAIL` и отдельной строкой
   `STAGE5_IMPROVEMENT=YES|NO|INDISTINGUISHABLE`.
