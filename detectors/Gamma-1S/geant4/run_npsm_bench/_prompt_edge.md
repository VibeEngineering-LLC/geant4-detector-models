## Назначение

Этап 4: измерить сдвиг комптоновского края, вносимый непропорциональностью.
Это ПЕРВАЯ проверка против чужого измерения (авторы дают −20,0 кэВ для NaI и
¹³⁷Cs), а не против нашего же расчёта.

## Вход

```
python analyze_edge.py --run <csv> [--json out.json]
```

CSV — прогон стенда с моноэнергетическими фотонами. Шапка `ключ,значение`
(нужны `energy_keV`, `npsm_enabled`), затем таблица гистограммы рассеяний,
затем пустая строка и таблица `bin_keV,count_edep,count_light`.

Разбор шапки — импортом `parse_csv` из `analyze_ncompt.py` того же каталога

Вторую таблицу читать самому: найти строку `bin_keV`, дальше тройки чисел.

## Что считать

**Теоретический край:** `E_edge = E · (2E/511) / (1 + 2E/511)`, где E в кэВ.

**Калибровка.** В шкале СВЕТА пик полного поглощения смещён вниз. Найти его как
бин с максимумом `count_light` в области `[0,2·E, 1,05·E]` (бин 0…1 кэВ
исключить всегда), уточнить положение как центр тяжести по бинам выше половины
максимума. Коэффициент `k = E / положение_ППП_в_свете`. Спектр по свету
калибруется умножением шкалы на `k` — ровно так работает реальный прибор,
калиброванный по линии.

**Положение края — точка перегиба на спаде.** Порядок:
1. Сгладить кривую скользящим средним по 9 бинам.
2. Взять численную производную.
3. В области `[0,7·E_edge, 1,15·E_edge]` (в калиброванной шкале для света, в
   собственной для энергии) найти бин с НАИБОЛЕЕ ОТРИЦАТЕЛЬНОЙ производной —
   это и есть точка перегиба.
4. Уточнить положение параболой по трём точкам вокруг минимума производной.

**Считать для ДВУХ кривых одного и того же прогона:**
- `count_edep` — шкала энергии, край здесь эталонный, модель на него не влияет;
- `count_light` после калибровки на `k` — здесь край смещён моделью.

**Сдвиг** = положение края по свету (калиброванному) − положение края по энергии.

## Критерии (назначены ДО прогона, из плана)

| № | Критерий | Порог |
|---|---|---|
| К-1 | край по ЭНЕРГИИ совпадает с теоретическим | расхождение ≤ 5 кэВ |
| К-2 | знак сдвига отрицательный | сдвиг < 0 |
| К-3 | величина сдвига | 12…28 кэВ по модулю (рамка вокруг опубликованных 20,0) |
| К-4 | прогон с `npsm_enabled = 0` | сдвиг не более 3 кэВ по модулю |

К-1 проверяет сам метод поиска края: если он не находит известный край в
шкале энергии, его показания в шкале света ничего не значат.
К-4 — мутация; при выключенной модели свет тождествен энергии, и сдвиг обязан
исчезнуть. Если прогон с выключенной моделью не подан — К-4 объявляется
непроверенным, итог FAIL.

## Вывод

1. Строки: энергия, теоретический край, край по энергии, положение ППП в свете,
   коэффициент `k`, край по свету калиброванный, сдвиг.
2. Блок «КРИТЕРИИ» К-1…К-4 с порогом, фактом, PASS/FAIL.
3. Блок «ТРЕБУЕТ ТОЛКОВАНИЯ» (печатать всегда): если в области края меньше
   200 отсчётов суммарно; если производная имеет несколько сравнимых минимумов
   (различие менее 20 %) — значит край размыт и точка перегиба неоднозначна.
4. Итог `STAGE4_EDGE_SHIFT=<число> keV` и `STAGE4_ACCEPTANCE=PASS|FAIL`.

## Ограничения

- `sys.stdout.reconfigure(encoding="utf-8")` первой строкой в `main`.
- Только stdlib + numpy, scipy НЕ использовать.
