# Спека: анализатор собственного вклада в разрешение (этап 3)

Ты — генератор кода на Python 3.11 (Windows). Верни ОДИН ПОЛНЫЙ файл, целиком,
без пояснений вне кода. Комментарии — по-русски.

Формат вывода — строго:

```
=== FILE: analyze_sigma_intr.py ===
<полный текст>
```

## Назначение

Этап 3 плана внедрения непропорциональности. Модель светового выхода уширяет
пик полного поглощения сама по себе: разные события одной энергии дробят её
по-разному, и взвешенная сумма получается разной. Светособирание и ФЭУ в стенде
не моделируются, поэтому измеренная ширина пика в спектре «по свету» И ЕСТЬ
собственный вклад `σ_intr`.

## Вход

```
python analyze_sigma_intr.py --runs "out/s3_*.csv" [--json out/sigma_intr.json] [--csv out/sigma_intr.csv]
```

Каждый CSV — прогон стенда: шапка `ключ,значение`, затем таблица гистограммы
рассеяний, затем ПУСТАЯ строка и вторая таблица со строкой заголовка
`bin_keV,count_edep,count_light`. Нужны из шапки: `energy_keV`, `npsm_enabled`,
`particle`, `beam`, `n_events_processed`, `em_cut_mm`, `em_deex`.

**Разбор шапки НЕ писать заново:** в том же каталоге `analyze_ncompt.py` с
функцией `parse_csv(file_path)`. Подключить импортом
(`sys.path.insert(0, str(pathlib.Path(__file__).parent))`). Импорт не удался —
громкая ошибка и возврат 3, без тихого отката на свою реализацию.

Вторую таблицу (спектр) `parse_csv` не отдаёт — её читать самому: найти строку,
начинающуюся с `bin_keV`, и брать следующие строки как `центр_бина, count_edep,
count_light`, пока строки непусты и разбираются в три числа.

## Что считать

Для каждого прогона — по колонке `count_light`:

1. **Найти пик полного поглощения.** Он лежит вблизи `energy_keV`, но НИЖЕ неё
   (модель отнимает свет). Область поиска: от `0,3 * energy_keV` до
   `1,05 * energy_keV`. Пик = бин с максимумом счёта в этой области.
   Если максимум оказался на границе области — пометка `[край]` и точка
   исключается из регрессии, но печатается.
2. **Оценить фон под пиком** линейно по двум участкам шириной 5 % от энергии
   слева и справа от пика, отступив от него на 3 полуширины на полувысоте.
3. **Подогнать гауссиану** к пику за вычетом фона методом наименьших квадратов
   в окне ±3 полуширины. Свободные параметры: амплитуда, центроид, `σ`.
   Начальные приближения: амплитуда — максимум, центроид — положение
   максимума, `σ` — полуширина на полувысоте, делённая на 1,1774.
   Подгонку писать самому на numpy (метод Гаусса–Ньютона или простой перебор
   по `σ` с аналитическим решением для амплитуды и центроида) — scipy НЕ
   использовать.
4. Вернуть: `E_keV`, центроид, `σ_keV`, `σ/E` в процентах, число событий в
   пике, `ПШПВ = 2,3548 σ`, относительное смещение центроида
   `(центроид − E)/E` в процентах.

## Критерии приёмки (назначены ДО прогона)

| № | Критерий | Порог |
|---|---|---|
| С-1 | `σ_intr(E)` монотонно возрастает при E > 100 кэВ | нарушений нет |
| С-2 | `σ_intr/E` монотонно УБЫВАЕТ при E > 100 кэВ | нарушений нет |
| С-3 | центроид пика ниже энергии на всех точках | смещение < 0 везде |
| С-4 | прогон с `npsm_enabled = 0` | `σ` не больше ширины одного бина (1 кэВ) |

С-4 — мутация: с выключенной моделью спектр по свету совпадает со спектром по
энергии, а тот при полном поглощении — одна линия. Если `σ` там не нулевая,
измеряется не то, что заявлено. **Прогон с выключенной моделью обязан
присутствовать в наборе; если его нет — С-4 не «пропускается», а объявляется
непроверенным, и итог всего анализа FAIL.**

## Регрессия

По точкам с включённой моделью и E > 100 кэВ подогнать `σ_intr(E) = a * E^b`
(линейная регрессия в логарифмах). Напечатать `a`, `b` и коэффициент
детерминации. Отдельной строкой — `σ_intr/E` при 662 кэВ.

## Вывод

1. Таблица по прогонам: `E, центроид, смещение %, σ_keV, σ/E %, событий в пике,
   пометки`.
2. Блок «КРИТЕРИИ» — С-1…С-4 с порогом, фактом и PASS/FAIL.
3. Блок **«ТРЕБУЕТ ТОЛКОВАНИЯ»**, печатается всегда: точки с пометкой `[край]`;
   точки, где событий в пике меньше 500 (статистика ненадёжна); точки, где
   подгонка не сошлась. Пусто — печатать «пусто».
4. Итог `STAGE3_ACCEPTANCE=PASS|FAIL`; при `--json` — машинный отчёт, при
   `--csv` — таблица.

## Ограничения

- `sys.stdout.reconfigure(encoding="utf-8")` первой строкой в `main`.
- Только stdlib + numpy.
- Ни одного тихого пропуска: нет файла, нет поля, пустой спектр, не сошлась
  подгонка — сообщение и ненулевой возврат либо явная пометка в таблице.
