## Метод масштабирования (09.08.2026, действующий)

Рисунок 1.1 размеров не несёт. Контурные линии сняты промером сканлиниями по
полноразмерному скану: чернота суммируется по полосе строк (или столбцов), от
чего сплошные контуры усиливаются, а штриховка под 45° размывается. Метод —
скилл `photo-metrology`. Ось разреза x = 664,0 px, плоскость наружного торца
головки (z = +41) y = 568,1 px.

**Масштаб задан ДЛИНОЙ устройства детектирования: 315 мм ↔ 383,9 px, то есть
1,2187 px/мм.**

Диаметр устройства для привязки НЕ ГОДИТСЯ: там, где детектор стоит в канале,
его контур слит со стенкой канала в линию толщиной 14–18 px, а внутри контура
идёт точечная заливка без чёткого края; кандидаты на «диаметр» лежат в полосе
77–112 px (Ø63…Ø92 при любом разумном масштабе). Длина меряется между двумя
чёткими торцами и даёт базу втрое больше.

### Окно масштаба по паспортным массам

Масса идёт как s⁻³, поэтому паспорт ограничивает масштаб с ДВУХ сторон:

| Ограничение | Источник | Даёт |
|---|---|---|
| свинец не менее 165 кг | паспорт ДЦКИ.412131.001 ПС, табл. 2.2 | s ≤ 1,2508 |
| экран-защита не более 231 кг | РЭ, п. 1.2.14 | s ≥ 1,1927 |

Принятый масштаб 1,2187 лежит внутри окна почти посередине. Отсюда точность
всей геометрии — **±2,4 % по любому линейному размеру**.

Модель на этом масштабе даёт: свинец 178,4 кг, экран-защита без тележки
216,5 кг (свинец + сталь 35,2 + медь 1,65 + кадмий 1,28).

### Про «свинец 50 мм»

Промер даёт толщину свинца 45 мм. Ранее задававшиеся 50 мм потребовали бы
s = 1,171; тогда экран-защита весит 244 кг против паспортных «не более 231».
С паспортом 50 мм не сходятся, в модель не берутся. Разница 45 против 50 —
это 2,5 мм свинца на пути, для рабочего диапазона от 50 кэВ несущественно.

### Что промер даёт (мм, от центра кристалла)

| Величина | Значение |
|---|---|
| полость под сосуд | Ø182,2 × 127,6 (z от −32,4 до +95,2) |
| канал под головку | Ø90,6, сквозной |
| свинец блока снаружи | Ø278,3 |
| стальной кожух | 7,5 мм, наружный Ø293,4 |
| шейка выше второй ступени | Ø179,7 (z от −68,1 до −163,2) |
| шейка ниже | Ø159,2 (до z = −414,2) |
| крышка | z от +100,7 до +163,7 |
| свинцовая пробка канала | Ø90,6 × 51,9, верх z = −372,4 |
| высота экрана-защиты в модели | 595,5 |

Вкладыши Cu 1,5 и Cd 1,2 мм на разрезе не показаны — единственные подгоночные
величины, взяты по паспортным массам меди (не менее 1,6 кг) и кадмия
(не менее 1,2 кг); модель даёт 1,65 и 1,28 кг.

Самопроверка, которая не закладывалась: в полость высотой 127,6 мм сосуд
Маринелли 1 л (H = 112 по чертежу изготовителя) входит с зазором 10 мм снизу
и 5 мм сверху.

## Куда это перенесено

`geometry/G1SDetector.hh`, структура `ShieldGeom` — все уровни и радиусы с
пометкой происхождения; `geometry/G1SDetector.cc`, `BuildShield` — тело
на `G4Polycone`. Разрез построенной модели рисует `geometry/plot_geom.py` по
выгрузке `DumpGeometry()` (переменная окружения `G1S_DUMP_GEOM`), то есть по
тому, что Geant4 собрал, а не по замыслу в исходнике.

**Устаревшее:** `analysis/draw_section_v5.py` и прежняя редакция этого файла
опирались на пережатый растр 466×786 и брали за диаметр детектора обвод
колодца сосуда (52 px), отчего получались наружный габарит Ø264 и полость
Ø156. Оба числа заменены промером по полноразмерному скану.
