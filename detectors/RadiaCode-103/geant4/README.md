# Geant4 — RadiaCode-103

Комплект геометрии RC-103 для Geant4: корпус-envelope, электроника (плата, LiPo,
EMI-ткань, дисплей), детекторный узел (CsI(Tl) 10³ + SiPM + ESR в капсуле).

Полное описание модели, системы координат и провенанса чисел —
[`docs/GEANT4-MODEL.md`](docs/GEANT4-MODEL.md).

## Что здесь есть и чего нет

| Есть | Где |
|---|---|
| SSOT-геометрия (все внутренности + корпус-примитив) | `gdml/detector/RC103_detector.gdml` |
| Генератор тесселированных GDML из STL | `scripts/stl_to_gdml.py` |
| C++ загрузчик STL через CADMesh | `cadmesh/` |
| Рендер Geant4 в 4 вида (спереди/сбоку/разрез/три четверти) — через общий инструмент `common/tools/gdml_multiview.cc` (грузит GDML напрямую, C++-дублирование геометрии не потребовалось) | `verify/RC103_view_{front,side,section,iso}.png`, монтаж `RC103_multiview.png`, сборщик `geometry/assemble_multiview.py` |
| Разрез с размерными линиями (matplotlib, не рендер) | `scripts/dimensioned_section.py` → `verify/RC103_dimensioned_section.png` |
| Обмер по рентгену и Blender bbox (кросс-проверка координат) | `verify/xray_measure.json`, `verify/blender_bbox_rc103-2.json` |
| Журнал инцидентов этой ветки (GDML-валидация) | `audit/project-incidents.md` |

**Намеренно НЕ в репозитории** (восстанавливается из исходников):

- `gdml/full/RC103_full.gdml` и `gdml/case_mesh/RC103_case_mesh.gdml` —
  генерируются `stl_to_gdml.py` из `Rc-103.stl.bak`;
- `Rc-103.stl(.bak)` и `RC103_model.blend` — исходники в референсной папке
  оператора, вне репозитория.

## Статус: GDML провалидирован Geant4 (26.08.2026)

Материал `G4_Si` самоссылался в GDML (копия того же бага, что был в RC-110) —
крашил `G4GDMLParser`. **Исправлено**, мутационно проверено (P-001,
`audit/project-incidents.md`). После фикса прогнан штатный
`G4PVPlacement::CheckOverlaps()` по всей геометрии — все найденные протрузии
(SiPM/carrier в нишу капсулы, дисплей в стенку корпуса, USB/PCB без вырезов)
оказались прямым следствием уже задокументированных упрощений примитивов
(«Ограничения модели» в `docs/GEANT4-MODEL.md`), с точной величиной для
каждой; правка координат не потребовалась. Плата, аккумулятор, EMI-ткань и
дисплей уже смоделированы.

Не смоделированы: U-вырез платы, fillet капсулы R≈5, ниша SiPM Ø11×2.2мм,
SMD, вырезы под USB/окно дисплея в корпусе (сознательные упрощения).

## Ограничение платформы

GDML-модуль **есть** в отдельной сборке `C:\geant4-gdml` (статическая, с
Xerces-C++, без OpenGL — см. `detectors/RadiaCode-110/geant4/README.md`,
раздел про GDML-тулчейн, тот же на этой машине). Основная рабочая сборка
`C:\geant4` — по-прежнему без GDML (prebuilt CERN, нет Xerces-C).
