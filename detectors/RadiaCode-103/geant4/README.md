# Geant4 — RadiaCode-103

Комплект геометрии RC-103 для Geant4: корпус-envelope, электроника (плата, LiPo,
EMI-ткань, дисплей), детекторный узел (CsI(Tl) 10³ + SiPM + ESR в капсуле).

Полное описание модели, системы координат и провенанса чисел —
[`docs/GEANT4-MODEL.md`](docs/GEANT4-MODEL.md).

**Состав этого репозитория — только то, что написано/сгенерировано и проверено
запуском в этой сессии** (по прямому требованию оператора 26.08.2026: «оставить
только твоё и проверенное», позже уточнено до «оставить только твой комплект, всё
лишнее удалить»). Никаких скопированных-но-не-прогнанных файлов здесь нет.

## Статус: GDML провалидирован Geant4 (26.08.2026)

Материал `G4_Si` самоссылался в GDML (копия того же бага, что был в RC-110) —
крашил `G4GDMLParser`. **Исправлено**, мутационно проверено (P-001,
`audit/project-incidents.md`). После фикса прогнан штатный
`G4PVPlacement::CheckOverlaps()` по всей геометрии — все найденные протрузии
оказались прямым следствием уже документированных упрощений примитивов (ниша
SiPM, вырезы под USB/окно дисплея/капсулу в PCB не смоделированы), с точной
величиной для каждой; правка координат не потребовалась.

## Ограничение платформы

GDML-модуль **есть** в отдельной сборке `C:\geant4-gdml` (статическая, с
Xerces-C++, без OpenGL — тот же тулчейн, что для RC-110). Основная рабочая
сборка `C:\geant4` — по-прежнему без GDML (prebuilt CERN, нет Xerces-C).

## Провенанс

Источник — референсная папка RC-103 оператора (локальная, вне репозитория),
подкаталог `geant4/`, состояние на 2026-08-26. Референсная папка содержит
больше файлов (STL-загрузчики, генератор тесселированных GDML, обмер по
рентгену, первый verify-скрипт) — они прочитаны при разборе, но не собирались
и не запускались в этой сессии, поэтому в этот репозиторий не перенесены.
