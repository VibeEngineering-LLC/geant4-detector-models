# Назначение

Понуклидное разложение спектра в свинцовом домике при ИСХОДНЫХ активностях,
взятых из открытого фона, плюс энергетическая зависимость ослабления по каждому
нуклиду. Ничего не подгоняется: активности переносятся как есть, а ослабление
берётся из отношения МК-шаблонов «с домиком / без домика», посчитанных одной и
той же программой в одной и той же геометрии.

Выход: текстовые таблицы в stdout и PNG с двумя панелями.

# Шапка

`# -*- coding: utf-8 -*-` и docstring по назначению выше. Отдельной строкой

# Функция `fit_open()`

Подгонка открытого фона, чтобы получить ИСХОДНЫЕ активности. Использует функции
модуля `ps`, своей реализации не писать.

```python
cnt_o, e_o, live_o, _ = ps.read_meas(ftc.MEAS_NAME, ftc.CAL_ROOM)
cps_o, var_o, hm_o = ps.load_cps(ps.FMT_OPEN, ftc.MUON_CSV)
```
Если `hm_o` ложно — `sys.exit("нет мюонного шаблона для открытого фона")`.
Далее `names, A_o, V_o = ps.columns_on_grid(cps_o, var_o, e_o, hm_o)`,
отбор `sel = (e_o >= ftc.E_LO) & (e_o < ftc.E_HI)`.

⚠ `ftc.fit` работает в ОТСЧЁТАХ: матрица подаётся как `A_o * live_o`, измерение —
сырым счётом `cnt_o[sel]`, веса `1/sqrt(max(счёт, 1))`. Возвращает КОРТЕЖ
`(amp, sd, pred, chi2ndf, shape)`, не словарь. Печать подгонки подавить через
`io.StringIO()` + `contextlib.redirect_stdout`.

Возвращает `(dict(zip(names, amp)), names)`.

# Функция `nuclide_activities(amp_map)`

Разворачивает три цепочечные амплитуды в ПОНУКЛИДНЫЕ, по формулам действующей
постановки (те же, что в `fit_physical_chains.main`):

```
A_K40   = amp_map["K40"]
A_Ra226 = amp_map["Ra226_chain"]
A_Pb214 = A_Bi214 = A_Ra226 * (1 - ps.F_RN)
A_Ac228 = amp_map["Th232_chain"]
A_Pb212 = A_Bi212 = A_Ac228 * ps.R_TH * (1 - ps.F_TN)
A_Tl208 = fpc.TL208_BRANCH * A_Bi212
A_mu    = amp_map["mu"]
```
⚠ Имена ключей в `amp_map` именно такие: `"K40"`, `"Ra226_chain"`, `"Th232_chain"`,
`"mu"` — их даёт `fpc.build_columns`, не выдумывать другие. Если ключа нет —
напечатать имеющиеся ключи и `sys.exit(1)`.

Возвращает словарь `{имя_нуклида: активность}` в порядке `fpc.NUCS + ["mu"]`.

# Функция `per_nuclide_spectra(fmt, muon_csv, e_grid, acts)`

Собирает вклад КАЖДОГО нуклида отдельно, в имп/с на сетке измерения.

Для каждого `nuc` из `fpc.NUCS`: читает шаблон `os.path.join(ftc.TEMPLATE_DIR, fmt % nuc)`
через `ftc.read_template`, сворачивает `ftc.rcspec.fold(arr, "103", tail_T=ps.TAIL_T)`,
переводит на сетку `ps.to_meas_grid(col, e_grid)` и домножает на `acts[nuc]`.
Мюоны: читает `muon_csv` тем же ридером, так же сворачивает и переводит, домножает
на `acts["mu"]`.
Отсутствие файла — печать пути и `sys.exit(1)`.

Возвращает словарь `{имя: массив имп/с}`.

# Функция `transmission(e_grid)`

Коэффициент пропускания по энергии для каждого нуклида: отношение шаблона с
домиком к шаблону без домика, оба на сетке `e_grid`, БЕЗ домножения на активности
(активность сокращается).

⚠ Оба шаблона статистически шумные, а знаменатель местами близок к нулю. Поэтому:
считать отношение только там, где ЗНАМЕНАТЕЛЬ выше порога `1e-3` от своего
максимума; в остальных точках писать `np.nan`. Дополнительно сгладить обе кривые
скользящим средним по 25 каналам ДО деления (свёртка `np.convolve` с ядром
`np.ones(25)/25`, режим `"same"`), иначе кривая рассыпается в шум и читаться не будет.
Сглаживание применять к обеим кривым одинаково — оно сокращается в отношении там,
где спектр гладкий, и лишь подавляет шум там, где его нет.

Возвращает словарь `{имя: массив T(E) с nan}`.

# Функция `report(acts, spec_shield, meas_shield, live_s, e_s)`

Печатает три таблицы.

1. **Исходные активности** — те, что перенесены из открытого фона: имя, значение,
   единица (`Бк/кг`, для `mu` — `с^-1`). Заголовок обязан прямо говорить, что это
   МОДЕЛЬНАЯ ОЦЕНКА, а не измерение.

2. **Вклад нуклидов в спектр в домике** — по всему интервалу `ftc.E_LO..ftc.E_HI`:
   имя, полный счёт от нуклида в имп/с, доля в процентах от суммы модели.
   Строки отсортировать по убыванию вклада. Последней строкой — сумма и общая
   доля 100 %, а также измеренная скорость счёта для сравнения.

3. **Вклад по полосам** `ftc.BANDS`: строка — полоса, столбцы — доля каждого
   нуклида в процентах от модельной суммы в этой полосе, плюс столбец «измерено,
   имп/с» и «модель, имп/с». Печатать компактно: имена столбцов сокращённые из `RU`.
   Доли считать ДО округления. Полосы, где модель нулевая, помечать прочерком.

# Функция `draw(...)`

Фигура `plt.subplots(2, 1, figsize=(11, 10), gridspec_kw={"height_ratios": [3, 2]})`.

**Верхняя панель — разложение спектра в домике.**
Измерение: `step(e_s, meas_shield, where="mid", color="#111111", lw=1.0, label="измерено, домик")`.
Вклады нуклидов — стопкой (`stackplot` либо последовательные `fill_between`),
в порядке возрастания полного вклада, чтобы мелкие лежали снизу и не тонули;
`linewidth=0`, без прозрачности, цвета из `COLORS`, подписи из `RU`.
Сверху — линия полной модели, цвет `#d62728`, `lw=1.4`, подпись «модель, сумма».
Ось Y логарифмическая; нижний предел — `0.5 *` минимум положительных значений
измерения, верхний — `2 *` максимум измерения. Ось X `set_xlim(ftc.E_LO, ftc.E_HI)`.
Подпись Y «скорость счёта, имп/с на канал». Заголовок «RadiaCode-103: разложение
спектра в свинцовом домике при исходных активностях».
Легенда ВНЕ поля данных: `legend(loc="upper center", bbox_to_anchor=(0.5, -0.08), ncol=5, frameon=False)`;
подпись оси X у верхней панели пустая.

**Нижняя панель — пропускание T(E).**
Для каждого нуклида — линия `plot(e_s, T[nuc], color=COLORS[nuc], lw=1.2, label=RU[nuc])`.
Ось Y логарифмическая, подпись «пропускание домика T(E) = с домиком / без домика».
Ось X — та же, подпись «энергия, кэВ», `set_xlim` тот же.
Горизонтальная опорная линия на уровне 1.0: `axhline(1.0, color="#666666", lw=0.8, ls="--")`.
Легенда справа вне поля: `legend(loc="upper left", bbox_to_anchor=(1.005, 1.0), frameon=False)`.
Подписи делений оси Y — обычными числами:
`ax.yaxis.set_major_formatter(matplotlib.ticker.ScalarFormatter())`.

`fig.tight_layout()`, `fig.savefig(OUT_PNG)`, печать полного пути.
