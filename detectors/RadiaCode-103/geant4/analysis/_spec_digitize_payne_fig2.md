# Алгоритм
1. Открыть PDF через PyMuPDF (`import fitz`). Взять страницу, чей текст содержит блок, начинающийся с `Fig. 2.`; если таких нет — отказ с кодом 2 и сообщением по-русски.
2. Собрать `page.get_drawings()`. Панель CsI(Tl) определить так: среди прямоугольников-рамок (элемент типа `re`, обводка чёрная) выбрать тот, чей `rect` содержит все три синие кривые (см. п. 3). Если не найден — отказ.
3. Синие кривые: объекты, у которых `color` отличается от (0,0,0) и покомпонентно отстоит от (0.310, 0.506, 0.741) не более чем на 0.05. Классифицировать по полю `dashes`: содержит `0 6` → `T_m40`; равно `[] 0` → `T_0`; содержит `3 3` → `T_p40`. Должны найтись ровно три; иначе отказ с перечислением найденного.
4. Калибровка. Внутри панели найти штрихи: горизонтальные короткие отрезки у левого края (x начала ≈ x0 рамки, длина по x < 5) — это Y-деления; вертикальные отрезки у нижнего края с длиной по y от 2.0 до 4.0 — это X-деления. Отсортировать. Требовать РОВНО 7 Y-делений и РОВНО 4 длинных X-деления; иначе отказ.
   - Ось Y линейная: подогнать `value = a*y + b` методом наименьших квадратов по 7 парам (y_тик, значение из ряда 0.9…1.5 снизу вверх). Максимальная невязка должна быть < 0.002; иначе отказ.
   - Ось X логарифмическая: подогнать `log10(E) = c*x + d` по 4 парам (x_тик, log10 из ряда 0, 1, 2, 3). Максимальная невязка по log10 < 0.01; иначе отказ.
5. Точки кривой: пройти `items` объекта по порядку, для каждого элемента `('l', p1, p2)` взять обе точки; собрать последовательность, удаляя подряд идущие дубликаты (расстояние < 1e-6). Перевести каждую точку в (E_кэВ, отн. выход) по калибровке. Отсортировать по E по возрастанию; при совпадающих E усреднить значение.
6. Нормировка: для каждой кривой вычислить значение при 662 кэВ линейной интерполяцией по log10(E) и добавить колонку `rel_to_662 = value / value_662`. Если 662 кэВ вне диапазона кривой — записать в этой колонке пустое значение и напечатать предупреждение.
