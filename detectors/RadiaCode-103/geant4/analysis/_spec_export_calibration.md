# ТОЧНЫЕ СИГНАТУРЫ (не менять)

`FM.measure_fwhm(counts, *, energy_keV=..., energy_cal=..., window_factor=...,
methods=...)` — всё кроме `counts` именованное. Возвращает объект с полями:
`passed` (bool), `reason` (str), `fwhm_keV`, `fwhm_uncertainty_keV`,
`centroid_channel`, `centroid_keV`, `significance_sigma`, `net_area`,
`per_method` (dict метод->кэВ). Отказ — нормальный возврат с `passed=False`,
но вызов всё равно оборачивать в try/except.

`rcspec.fwhm(E, "103")` — действующая ПШПВ в кэВ, принимает скаляр и массив.
`read_rcxml.read(path)` — список объектов; берётся `[0]`; поля `counts`
(массив), `live` (секунды), `coef` (кортеж коэффициентов калибровки прибора).

# Логика

1. **Найти файлы спектров** в `BASE` через `glob.glob(os.path.join(BASE, "*.xml"))`.
   Классифицировать по имени файла: содержит «Фон 7» -> ключ `bg7`, подпись
   «фон помещения, 7 суток»; содержит «домик 23» -> `shield23`, «фон в свинцовой
   защите, 23 суток»; содержит «RC103» -> `cs137`, «проба с цезием-137».
   Если какого-то файла нет — пропустить его молча, но отметить в выходе.

2. **Спектры.** Для каждого найденного: `counts = smp.counts[:-1]`,
   энергия каналов по `CAL` (полином от младшего коэффициента),
   скорость счёта `counts / smp.live`. Прорядить с шагом 2 канала.
   Выгружать: `energy` (список), `rate` (список, отсчёты в секунду на канал),
   `live_s`, `total_counts`, `label`.

3. **Точки ПШПВ.** Измерять для набора линий, у каждой указан спектр, в
   котором её надо мерить:
   ```python
   LINES = [
       ("bg7",   238.63, "Pb-212"), ("bg7",   351.93, "Pb-214"),
       ("bg7",   583.19, "Tl-208"), ("bg7",   609.31, "Bi-214"),
       ("bg7",   911.20, "Ac-228"), ("bg7",  1120.29, "Bi-214"),
       ("bg7",  1460.82, "K-40"),   ("bg7",  1764.49, "Bi-214"),
       ("bg7",  2614.51, "Tl-208"),
       ("cs137",  32.19, "Ba K-alpha"), ("cs137", 661.66, "Cs-137"),
   ]
   ```
   Для каждой линии вызвать `measure_fwhm` с `window_factor=1.25` и
   `methods=MM`. Собрать два списка:
   - `points` — принятые: спектр, нуклид, табличная энергия, центроида,
     отклонение центроиды от табличной, ПШПВ, её погрешность, значимость,
     действующая `rcspec.fwhm`, отношение измеренной к действующей,
     значения по методам (`per_method`);
   - `refused` — отказавшие: спектр, нуклид, энергия, причина (`reason`),
     значимость (если есть).

4. **Устойчивость по окнам.** Для линий 32.19 (cs137), 661.66 (cs137),
   1460.82 (bg7), 2614.51 (bg7) прогнать `window_factor` из
   `[0.9, 1.0, 1.25, 1.5, 1.75]` и выгрузить для каждой линии список пар
   (window_factor, ПШПВ или null если отказ) плюс значимость. Это диагностика:
   у настоящей линии ширина от окна почти не зависит, у утонувшей в континууме
   меняется или линия вовсе теряет значимость.

5. **Кривые разрешения** на сетке энергий
   `np.arange(20, 3000, 10)`:
   - `current` — действующая `rcspec.fwhm(E, "103")`;
   - `fit3_CA2` — подгонка `FWHM^2 = C + A2*E` МНК ПО КВАДРАТАМ ширин по
     принятым точкам (матрица `np.column_stack([np.ones_like(E), E])`,
     правая часть `W**2`), обратно `np.sqrt(np.maximum(C + A2*E, 0))`;
   - `fit3_A2` — подгонка чисто `FWHM^2 = A2*E` по тем же точкам
     (`A2 = sum(E*W^2)/sum(E*E)`).
   Выгрузить сетку и три списка значений, а также сами коэффициенты
   (`C`, `A2` для каждой формы) и остатки каждой формы в измеренных точках.
   ВАЖНО: подгонка ведётся по КВАДРАТУ ширины, не по ширине.

6. **Энергетическая шкала.** Выгрузить: коэффициенты `CAL`, коэффициенты
   калибровки прибора из файла `bg7` (`smp.coef`), и для каждой принятой
   точки — отклонение измеренной центроиды от табличной энергии по обеим
   шкалам (для приборной измерение повторить с `energy_cal=list(smp.coef)`).

7. **Блок `notes`** — словарь с уже установленными фактами, строками
   на русском (их страница печатает как есть, не вычисляя):
   - `resolution_ok`: на 32,2 и 661,7 кэВ действующая кривая совпадает с
     измерением в пределах 0,5 кэВ;
   - `k40_gap`: на 1460,8 кэВ измеренная ПШПВ 73,8 кэВ против 85,4 кэВ по
     действующей кривой, расхождение 16 процентов, измерение надёжно —
     21 сигма, три метода согласованы, устойчиво по окнам;
   - `tl208_not_measurable`: пик 2614,5 кэВ значим (5,0 сигма), но его ширина
     не определяется: измерение проходит только при одном размере окна, а
     полученное значение меньше, чем на 1460,8 кэВ, что физически невозможно;
   - `refit_worse`: пересчёт кривой по всем трём надёжным точкам ухудшает
     согласие на мягком конце, где действующая кривая совпадает с измерением.

8. Записать JSON в `OUT` (`ensure_ascii=False`, `separators=(",", ":")`),
   создав каталог при необходимости. Напечатать путь, размер файла в байтах,
   число принятых точек и число отказов.

# Требования

`sys.stdout.reconfigure(encoding="utf-8")` первой строкой в `main()`.
Все числа в JSON округлять: энергии и ширины до 2 знаков, скорости счёта до
8 значащих (использовать `round(float(x), 8)`), отношения до 3.
Вывод на русском. Обернуть в `def main():` и `if __name__ == "__main__": main()`.
Никаких заглушек и выдуманных чисел: если линия не измерилась — она идёт в
`refused` с настоящей причиной, а не подменяется нулём.
Переменные цикла не использовать вне цикла; списки перед `zip(*...)` и
`np.max(...)` проверять на непустоту.
