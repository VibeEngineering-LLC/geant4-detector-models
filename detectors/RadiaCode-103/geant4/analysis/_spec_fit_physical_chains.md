# Назначение

Шаблонное разложение фона RC-103 методом 1 с ФИЗИЧЕСКИ СВЯЗАННЫМИ цепочками. Заменяет прежнюю постановку, где 8 амплитуд были независимы и NNLS выдавал нефизичный результат (дочерние Pb-214/Bi-214 вдвое больше родителя Ra-226, что в замкнутой цепочке невозможно).

Docstring обязан объяснить постановку:
- прежнее уравнение `min||W(Ax-y)||, x>=0` не содержало связей между компонентами x, поэтому нефизичное решение было для него легальным;
- новое уравнение параметризует ЦЕПОЧКИ, а не нуклиды;
- утечка радона/торона может ТОЛЬКО уменьшить дочерних относительно родителя, никогда не увеличить — это заложено в параметризацию структурно.

# Физическая модель (реализовать ровно так)

Свободные параметры: 4 линейные амплитуды (A_K, A_Ra, A_Th, A_mu) и 3 нелинейные (f_Rn, r_Th, f_Tn).

Связи внутри цепочек:
- ряд урана: `A(Pb214) = A(Bi214) = A_Ra * (1 - f_Rn)`, где `f_Rn` — коэффициент эманирования радона (Rn-222, T½=3.8 сут, успевает диффузионно уйти). Сам Ra-226 распадается в матрице, его вклад идёт с амплитудой `A_Ra` без множителя.
- ряд тория: `A(Pb212) = A(Bi212) = A_Th * r_Th * (1 - f_Tn)`, где `r_Th = A(Th-228)/A(Ra-228)` — сдвиг равновесия в верхней части ряда (Th-228, T½=1.9 года, может быть химически отделён), `f_Tn` — эманирование торона (Rn-220, T½=55.6 с, диффузионная длина ~1/77 радоновой). Ac-228 (дочерний Ra-228) идёт с амплитудой `A_Th` без множителей.
- ветвление: `A(Tl208) = 0.3594 * A(Bi212)` — доля распадов Bi-212, идущая в Tl-208 (остальные 64.06% — альфа-канал в Po-212).

Итоговая модель спектра:
```
y = A_K * T_K40
  + A_Ra * [ T_Ra226 + (1-f_Rn) * (T_Pb214 + T_Bi214) ]
  + A_Th * [ T_Ac228 + r_Th*(1-f_Tn) * (T_Pb212 + T_Bi212 + 0.3594*T_Tl208) ]
  + A_mu * T_mu
```
где `T_X` — шаблон нуклида X на 1 Бк/кг (для мюонов — на 1 мюон/с).

# Метод решения

При ФИКСИРОВАННЫХ (f_Rn, r_Th, f_Tn) модель ЛИНЕЙНА по (A_K, A_Ra, A_Th, A_mu) — значит:
1. строим сетку по трём нелинейным параметрам;
2. в каждом узле собираем матрицу 4 столбцов и решаем NNLS (через `ftc.fit`, переиспользуя готовое ядро с итеративным учётом дисперсии шаблонов);
3. выбираем узел с минимальным значением целевой функции.

Чтение измерения — дословно так:

Мюоны читаются ОТДЕЛЬНО (у них другой файл и другая нормировка — на число разыгранных мюонов, а не на t_run_s):

Восемь нуклидных шаблонов читаются циклом по `NUCS` из `ftc.TEMPLATE_DIR` по `TEMPLATE_FMT`, у них нормировка по `meta["t_run_s"]`.

Сборка матрицы в `evaluate` — дословно:
```python
A = np.zeros((len(e_meas), len(cols)))
V = np.zeros_like(A)
for k, (c, v) in enumerate(zip(cols, vars_)):
    A[:, k] = ftc.fl.rebin_model_to_meas(np.arange(len(c)) + 0.5, c, e_meas)
    V[:, k] = ftc.fl.rebin_model_to_meas(np.arange(len(v)) + 0.5, v, e_meas)
sel = (e_meas >= ftc.E_LO) & (e_meas < ftc.E_HI)
A, V, y, e_sel = A[sel], V[sel], cnt[sel], e_meas[sel]
A_counts, VAR_counts = A * live, V * live * live
w = 1.0/np.sqrt(np.maximum(y,1.0)) if criterion=="A" else 1.0/np.maximum(y,1.0)
amp, sd, pred, chi2ndf, shape = ftc.fit(A_counts, y, w, names, "", "", var_counts=VAR_counts)
```
