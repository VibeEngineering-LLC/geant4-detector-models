# Функция `read_template(path)`

Читает CSV с двумя блоками. Первый блок начинается строкой `metric,value` — далее строки `ключ,значение`, значения приводить к `float`, при неудаче оставлять строкой. Второй блок начинается строкой, начинающейся с `bin_keV` — далее строки `бин,counts,cps`. Пустые строки пропускать.

Возвращает `(meta, arr)`, где `arr` — массив `numpy` длиной `int(max(bin)) + 1`, в который по индексу `int(bin)` записана ТРЕТЬЯ колонка (`cps`). Сетка 1 кэВ на бин. Если гистограмма пуста — `raise SystemExit` с именем файла.

# Функция `load_templates()`

Для каждого имени из `NUCS` строит путь `TEMPLATE_DIR/TEMPLATE_FMT % имя`. Отсутствующие копит в список `missing`, присутствующие читает через `read_template`, затем сворачивает с аппаратным разрешением: `folded = rcspec.fold(cps_raw, "103")`. Печатает по каждому найденному строку с `n_hits_in_crystal`, `cps_total`, `t_run_s` из `meta` и базовым именем файла. После цикла печатает отсутствующие с полным путём. Если не найдено ни одного — `SystemExit` с подсказкой прогнать `run_field` по спеке `run_field/_spec_run_field.md`. Возвращает `(names, cols, metas)`.

# Функция `degeneracy_report(A, names)`

Диагностика ДО подгонки. Нормировать столбцы `A` на их евклидову норму, посчитать матрицу `C = norm.T @ norm`, напечатать её таблицей с заголовком из имён. Посчитать сингулярные числа (`np.linalg.svd(norm, compute_uv=False)`), напечатать `cond = sv[0]/sv[-1]` с примечанием, что при значении больше 100 часть амплитуд не определится. Для каждой пары с `C[i,j] > 0.995` напечатать строку-предупреждение, что разделение этих двух звеньев недостоверно. Вернуть `cond`.

# Функция `metrics(pred_counts, meas_counts, n_par)`

Возвращает кортеж `(chi2_ndf, shape)`:
- `var = np.maximum(meas_counts, 1.0)`; `chi2 = sum((pred-meas)**2 / var)`; `ndf = max(len(meas)-n_par, 1)`; первый элемент `chi2/ndf`.
- `shape` — доля несовпадения формы: нормировать оба вектора на их суммы и вернуть `0.5 * sum(abs(pred/sum(pred) - meas/sum(meas)))`. Значение 0 означает совпадение форм, 1 — полное несовпадение. Если любая из сумм неположительна — вернуть `float("nan")`.

# Функция `fit(A_counts, meas_counts, weights, names, title, note)`

Взвешенный NNLS: `Aw = A_counts * weights[:, None]`, `yw = meas_counts * weights`, `amp, _ = nnls(Aw, yw)`. Ошибки амплитуд — из ковариации `cov = np.linalg.inv(Aw.T @ Aw)`, `sd = sqrt(max(diag(cov), 0))`; при `np.linalg.LinAlgError` заполнить `nan`. Посчитать `pred = A_counts @ amp` и метрики.

Печать: разделитель из `=` длиной 68, заголовок `РАЗЛОЖЕНИЕ <title>`, текст `note`, снова разделитель, затем таблица столбцов `звено | Бк/кг | ошибка | отн` (относительная ошибка в процентах). Пометки: если амплитуда равна нулю — `<-- обнулена NNLS`; если ошибка больше самой амплитуды — `<-- НЕ ОПРЕДЕЛЕНА (ошибка больше значения)`. Затем две строки: `chi2/ndf` с тремя знаками и `невязка формы` с четырьмя знаками и пояснением `(0 = формы совпали)`.

Возвращает `(amp, sd, pred, chi2ndf, shape)`.

# Функция `bands_report(pred, meas, e_meas, live)`

Таблица по полосам из `BANDS`: колонки `полоса,кэВ | измерено | модель | м/и`. Измеренное и модельное делить на `live` (получаютсяcps). Последняя строка — `полный` по всему диапазону `E_LO..E_HI`. При нулевом измеренном значении в отношении печатать `nan`.

# Функция `equilibrium_report(names, amp, sd, title)`

Для каждой тройки из `EQUILIBRIUM`, если обе амплитуды строго положительны, посчитать отношение `r` и его ошибку `er = r * sqrt((sd_a/a)^2 + (sd_b/b)^2)`, напечатать строку с `r`, `er`, ожидаемым значением, отношением `r/ожид` и пояснением. Заголовок блока должен подчёркивать, что равновесие ПРОВЕРЯЕТСЯ, а не постулируется. Если ни одной пары не напечатано — сказать об этом явно.
