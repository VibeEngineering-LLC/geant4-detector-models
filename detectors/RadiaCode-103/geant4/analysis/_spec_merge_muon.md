# Назначение

Сложить несколько независимых мюонных прогонов в один шаблон. Понадобилось
потому, что длинные прогоны на этой машине до конца не доживают: три подряд были
прекращены извне, один — на 450 млн историй из 500 млн. Вместо одного длинного
запускается несколько коротких с РАЗНЫМИ зёрнами, и результат складывается.

Складывать независимые прогоны корректно только при разных зёрнах: с общим зерном
выборки совпадают, и сумма даст не рост статистики, а умноженную на число прогонов
одну и ту же реализацию.

# Формат входных файлов

Блок метаданных «ключ,значение», пустая строка, строка-заголовок
`bin_keV,counts,per_muon`, затем данные через запятую. Ключи метаданных, которые
встречаются: `n_events`, `n_hits_in_crystal`, `n_overflow`, `r_disk_mm`,
`z_disk_mm`, `disk_area_cm2`, `pdg_expected_per_s`, `e_lo_gev`, `e_hi_gev`,
`max_edep_keV`.

# Правила сложения

- `counts` — суммируются побинно;
- `n_events`, `n_hits_in_crystal`, `n_overflow` — суммируются;
- `per_muon` — НЕ суммируется, а пересчитывается: `counts_сумма / n_events_сумма`.
  Это и есть смысл нормировки «на один мюон»;
- `max_edep_keV` — максимум по прогонам;
- `r_disk_mm`, `z_disk_mm`, `disk_area_cm2`, `pdg_expected_per_s`, `e_lo_gev`,
  `e_hi_gev` — обязаны СОВПАДАТЬ у всех слагаемых. Расхождение хотя бы в одном —
  печать имени ключа, обоих значений и `sys.exit(1)`. Складывать прогоны разной
  геометрии нельзя, и молча приводить их к одному нельзя тем более.

Дополнительно проверить РАЗЛИЧИЕ зёрен: если у двух файлов побинные `counts`
совпадают полностью, это признак общего зерна — печать обоих имён и `sys.exit(1)`.

# Интерфейс

```
python merge_muon_runs.py <выходной.csv> <вход1.csv> <вход2.csv> [...]
```
Меньше двух входных файлов — печать способа вызова и `sys.exit(2)`.
Отсутствующий файл — печать пути и `sys.exit(1)`.

# Выход

Тот же формат, что у входа: метаданные, пустая строка, заголовок
`bin_keV,counts,per_muon`, данные. В метаданные добавить строку `n_merged` —
число сложенных прогонов, и `merged_from` — имена входных файлов через точку с
запятой (только базовые имена, без путей).

Печать в stdout: по каждому входному файлу строка с `n_events` и
`n_hits_in_crystal`, затем итог — суммарные значения и путь выходного файла.
