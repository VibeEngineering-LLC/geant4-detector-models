# Назначение
Построить кривую относительного светового выхода CsI(Tl) или NaI(Tl) при ЗАДАННОЙ температуре
из трёх оцифрованных кривых Payne III (Fig. 2 при −40, 0, +40 °C). Оператор 03.09.2026: температура
помещения при измерениях фона RadiaCode-103 = 26 °C. ПЕРЕД интерполяцией скрипт проверяет
линейность по температуре и честно сообщает, обоснована ли интерполяция данными.

# CLI
`python payne_curve_at_T.py [--T 26] [--material CsI_Tl|NaI_Tl] [--nodes 60] [--selftest]`

# Данные
Входные CSV: `<каталог скрипта>/out/payne3_fig2_<material>_<label>.csv`, где material ∈ {CsI_Tl, NaI_Tl},
label ∈ {T_m40, T_0, T_p40}. Строки с `#` — комментарии; шапка `E_keV,rel_light_yield`; далее две
колонки чисел. Соответствие меток температурам: T_m40 = −40, T_0 = 0, T_p40 = +40 (словарь TEMPS).

# Логика main
1. Загрузить три кривые материала, отсортировать по E. Общий диапазон [lo, hi] = пересечение.
2. Сетка `grid` из `nodes` точек, логарифмически равномерная в [lo, hi]. Интерполировать каждую
   кривую на сетку ПО log10(E) (`np.interp(np.log10(grid), np.log10(E), Y)`).
3. Проверка линейности по T: `mid = 0.5*(y[T_m40] + y[T_p40])`, `dev = |mid − y[T_0]|`.
   Печатать max|откл.|, при какой E, среднее|откл.|. Порог 0.005 (= заявленная авторами
   погрешность подгонки 0,5 %). Печатать вывод «ЛИНЕЙНА»/«НЕ линейна». Если не линейна —
   предупредить, что интерполяция ниже выполнена как ОЦЕНКА, не результат.
4. Интерполяция значения при `--T`: функция `interp_at_T(y_dict, T)` — линейная ПО ЗНАЧЕНИЯМ между
   двумя ближайшими кривыми по температуре. T ≤ −40 → кривая −40; T ≥ +40 → кривая +40; иначе вес
   `w = (T−t0)/(t1−t0)` между соседними узлами, `(1−w)*y[t0] + w*y[t1]`.
5. Записать результат в `out/payne3_fig2_<material>_T<+T как целое>C.csv` с шапкой-комментарием:
   температура, способ (линейная интерполяция по значениям), результат проверки линейности
   (max|откл.| и порог), источник (Payne S.A. et al., IEEE TNS 61 (2014) 2771, OSTI 1762905),
   предупреждение «оцифровка графика, не табличные данные автора». Колонки `E_keV,rel_light_yield`.
6. Напечатать таблицу для E ∈ {10,20,40,80,150,300,430} кэВ (пропуская вне диапазона): E,
   значения при −40/0/+40 и при заданной T (ближайший узел сетки).

# selftest (обязателен, умеет краснеть)
На синтетике `grid=[10,100]`, `y={T_m40:[1.30,1.00], T_0:[1.20,0.99], T_p40:[1.10,0.98]}`:
- `interp_at_T(y,0)` обязана вернуть ровно кривую T_0 (иначе FAIL);
- `interp_at_T(y,20)` обязана дать полусумму T_0 и T_p40 (вес 0.5) с точностью 1e-9;
- МУТАЦИЯ: `interp_at_T(y,26)` НЕ должна совпасть с кривой T_0 (иначе интерполяция мертва → FAIL).
Печать `SELFTEST OK`/`SELFTEST FAIL: ...`, код возврата 0/1.
