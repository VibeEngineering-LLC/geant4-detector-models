2. Для каждой пары в PAIRS вычислить отклонение в сигмах: `nsig = abs(отношение - ожидание) / ошибка` (если ошибка > 0, иначе `float("nan")`).
3. Ось Y — категориальная, одна строка на пару (индекс `i` сверху вниз, `y = len(PAIRS) - 1 - i`, чтобы первая пара была сверху). Цвет точки — `RADON_COLOR`, если поле "что проверяет" равно `"радон"`, иначе `THORON_COLOR`.
4. Для каждой пары нарисовать `ax.errorbar([отношение], [y], xerr=[[min(ошибка, отношение)], [ошибка]], fmt="o", ms=9, color=цвет, capsize=4, zorder=3)` — `xerr` с обрезкой нижнего уса по `min(ошибка, отношение)`, чтобы левый ус не уходил в отрицательные значения на линейной шкале.
5. Отметить ожидаемое значение вертикальной чёрточкой на той же строке: `ax.plot([ожидание], [y], marker="|", color="black", ms=20, mew=2, zorder=4)`.
6. Подпись строки слева от оси (через `ax.set_yticks` и `ax.set_yticklabels` с меткой пары).
7. Справа от каждой точки текстом — отклонение в сигмах и физический смысл: `ax.annotate("%.1f σ — %s" % (nsig, что_проверяет_и_физика), xy=(отношение+ошибка, y), xytext=(8, 0), textcoords="offset points", fontsize=8, va="center")`.
