# Функция `prepare()`

Повторяет подготовку данных из `ftc.main()`, но ничего не печатает лишнего и возвращает данные для рисования.

1. `meas_path = os.path.join(ftc.MEAS_DIR, ftc.MEAS_NAME)`; если файла нет — `raise SystemExit` с путём.
2. `smp = ftc.read_rcxml.read(meas_path)[0]`; `cnt = smp.counts[:-1].astype(float)`; `ch = np.arange(len(cnt))`; `e_meas = np.asarray(sum(c * ch ** i for i, c in enumerate(ftc.CAL_ROOM)))`; `live = float(smp.live)`.
3. `names, cols, metas = ftc.load_templates()`.
4. Матрица `A`: для каждого столбца `A[:, k] = ftc.fl.rebin_model_to_meas(np.arange(len(c)) + 0.5, c, e_meas)`.
5. Маска `sel = (e_meas >= ftc.E_LO) & (e_meas < ftc.E_HI)`; применить к `A`, `cnt`, `e_meas`.
6. `A_counts = A * live`.
7. Две подгонки через `ftc.fit(...)` с теми же весами, что в `ftc.main()`: для A — `1.0 / np.sqrt(np.maximum(meas_counts, 1.0))`, для B — `1.0 / np.maximum(meas_counts, 1.0)`. Заголовки и пояснения можно передать краткие.
8. Вернуть словарь со всем нужным: `names`, `cols`, `e_sel`, `meas_counts`, `A_counts`, `live`, результаты обеих подгонок (амплитуды, ошибки, предсказание, chi2/ndf, невязка формы).
