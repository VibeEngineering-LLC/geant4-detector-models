# Назначение

Проверить, воспроизводит ли расчёт ослабление известного фона свинцовым домиком.
Активности нуклидов считаются УЖЕ ИЗВЕСТНЫМИ: они берутся из подгонки фона в
открытой комнате и в предсказание спектра в домике входят БЕЗ ИЗМЕНЕНИЙ.
Свободных параметров в предсказании нет — это проверка модели, а не подгонка.

Дополнительно (для диагностики) выполняется вторая, СВОБОДНАЯ подгонка тех же
столбцов с домиком к измерению в домике: она показывает, какие активности
«увидел бы» домик, если бы их подбирали. Расхождение свободной подгонки с
известными активностями — мера дефекта модели ослабления.

# Функция `load_cps(fmt, muon_csv)`

Аргументы: строка формата имени шаблона и путь к мюонному шаблону (пустая строка =
мюонов нет). Возвращает `(cps, var, has_muon)`.

Для каждого нуклида из `fpc.NUCS` строит путь `os.path.join(ftc.TEMPLATE_DIR, fmt % nuc)`,
читает `meta, arr, cnt_mc = ftc.read_template(path)`; при отсутствии файла печатает путь
и `sys.exit(1)`. Заполняет `cps[nuc] = ftc.rcspec.fold(arr, "103", tail_T=TAIL_T)` и
`var[nuc] = ftc.template_variance(cnt_mc, float(meta.get("t_run_s", 0.0)))`.

⚠ `ftc.template_variance` сворачивает СВОИМ вызовом `fold` без хвоста. Это принятое в
контуре приближение, менять его нельзя — просто вызывать как есть.

Если `muon_csv` непустой и файл существует: читает его тем же `ftc.read_template`,
кладёт `cps["mu"] = ftc.rcspec.fold(arr_mu, "103", tail_T=TAIL_T)` и
`var["mu"] = ftc.template_variance(cnt_mu, float(meta_mu.get("n_events", 0.0)))`,
`has_muon = True`. Иначе `has_muon = False`.

# Функция `to_meas_grid(col, e_meas)`

`return ftc.fl.rebin_model_to_meas(np.arange(len(col)) + 0.5, col, e_meas)`.
Однострочная, нужна чтобы не повторять вызов.

# Функция `read_meas(name, cal)`

Читает измерение: `smp = ftc.read_rcxml.read(os.path.join(ftc.MEAS_DIR, name))[0]`,
`cnt = smp.counts[:-1].astype(float)`, `ch = np.arange(len(cnt))`.
Если `cal` не `None` — шкала `e = sum(c * ch**i for i, c in enumerate(cal))`;
если `cal` есть `None` — берётся ПРИБОРНАЯ калибровка самого файла: `cal = smp.coef`.
Возвращает `(cnt, np.asarray(e, dtype=float), float(smp.live), tuple(cal))`.

# Функция `columns_on_grid(cps, var, e_meas, has_muon)`

Вызывает `names, cols, vars_ = fpc.build_columns(cps, var, F_RN, R_TH, F_TN)`.

⚠ ВАЖНО: `fpc.build_columns` включает мюонный столбец, только если модульный флаг
`fpc.NO_MUON` ложен И в словаре есть ключ `"mu"`. Поэтому перед вызовом установить
`fpc.NO_MUON = not has_muon`.

Затем переводит каждый столбец и каждую дисперсию на сетку измерения через
`to_meas_grid`, собирает матрицы `A` (каналы × столбцы) и `V` того же размера.
Возвращает `(names, A, V)`.

# Функция `bands_table(title, meas_cps, pred_cps, e_meas)`

Печатает заголовок `title`, затем таблицу по полосам `BANDS`: для каждой пары
`(lo, hi)` — сумма `meas_cps` и `pred_cps` по каналам с `lo <= e < hi`, и отношение
модель/измерение. Формат строки: `"%4d-%4d кэВ | %12.6f | %12.6f | %7.3f"`.
Последней строкой — итог по всему интервалу `ftc.E_LO..ftc.E_HI` с пометкой «ВСЕГО».
Отношение считать ДО округления, из полных сумм; при нулевом измерении печатать `nan`.
Возвращает список кортежей `(lo, hi, m, p, ratio)`.

# Функция `main()`

1. **Открытый фон.** `cnt_o, e_o, live_o, cal_o = read_meas(ftc.MEAS_NAME, ftc.CAL_ROOM)`.
   Печатает имя файла, живое время в часах и сутках, полный счёт и имп/с.

2. **Шаблоны без домика.** `cps_o, var_o, hm_o = load_cps(FMT_OPEN, ftc.MUON_CSV)`.
   Если мюонного шаблона нет — печатать явное предупреждение, работу продолжать.

3. **Подгонка по открытому фону.** `names, A_o, V_o = columns_on_grid(cps_o, var_o, e_o, hm_o)`.
   Отбор `sel = (e_o >= ftc.E_LO) & (e_o < ftc.E_HI)`, применить ко всем массивам.
   Веса пуассоновские: `w = 1.0 / np.sqrt(np.maximum(y_o, 1.0))`.
   Вызов: `amp, sd, pred_o, chi2_o, shape_o = ftc.fit(A_o*live_o, y_o, w, names, title, note, var_counts=V_o*live_o*live_o)`.
   `title` = "Открытый фон — источник известных активностей", `note` = строка с
   действующей постановкой (значения F_RN, R_TH, F_TN, TAIL_T).
   `ftc.fit` печатает таблицу амплитуд сама — подавлять её вывод НЕ нужно.

4. **Активности в физических единицах.** Из `amp` восстановить и напечатать
   активности по тем же формулам, что в `fit_physical_chains.main`:
   `A_K, A_Ra, A_Th` — первые три элемента, `A_mu` — четвёртый, если `hm_o`;
   `A_Pb214 = A_Bi214 = A_Ra * (1 - F_RN)`;
   `A_Pb212 = A_Bi212 = A_Th * R_TH * (1 - F_TN)`;
   `A_Tl208 = fpc.TL208_BRANCH * A_Bi212`.
   Печатать с пометкой, что это МОДЕЛЬНАЯ ОЦЕНКА, а не измерение.

5. **Измерение в домике.** `cnt_s, e_s, live_s, cal_s = read_meas(MEAS_SHIELD, None)`
   — калибровка приборная, из самого файла. Печатает имя, живое время, полный счёт,
   имп/с и КОЭФФИЦИЕНТЫ применённой калибровки (три числа).

6. **Шаблоны с домиком.** `cps_s, var_s, hm_s = load_cps(FMT_SHIELD, MUON_SHIELD_CSV)`.
   Если мюонного шаблона С ДОМИКОМ нет (`MUON_SHIELD_CSV` пуст или файла нет) —
   напечатать выделенное предупреждение: предсказание строится БЕЗ космической
   компоненты, и в жёсткой части ожидается дефицит. Это штатный режим первой итерации.

7. **Предсказание.** `names_s, A_s, V_s = columns_on_grid(cps_s, var_s, e_s, hm_s)`,
   отбор по `ftc.E_LO..ftc.E_HI`.
   ⚠ Число столбцов с домиком может отличаться от числа столбцов открытого фона —
   ровно на мюонный. Поэтому амплитуды переносить ПО ИМЕНАМ: построить
   `amp_map = dict(zip(names, amp))` и собрать вектор `amp_s = np.array([amp_map.get(n, 0.0) for n in names_s])`.
   Если какое-то имя из `names_s` отсутствует в `amp_map` — напечатать его и
   `sys.exit(1)`, молча нулём не подставлять.
   Предсказанный счёт: `pred_s_counts = (A_s @ amp_s) * live_s`.

8. **Сравнение.** Напечатать `bands_table` для домика: измерено и предсказано
   привести к имп/с (делить на `live_s`). Затем напечатать `chi2/ndf` и невязку формы
   через `ftc.metrics(pred_s_counts, y_s, 0)` — ноль параметров, потому что в
   предсказании не подбиралось НИ ОДНОГО.

9. **Ослабление.** Для каждой полосы напечатать три числа: ослабление по измерению
   (открытый фон / домик, оба в имп/с), ослабление по модели (предсказание открытого
   фона / предсказание домика) и их отношение. Полосы у двух измерений заданы на
   РАЗНЫХ энергетических сетках — суммировать каждое по своей сетке, это корректно,
   поскольку сравниваются интегралы по одинаковым интервалам энергии.

10. **Свободная подгонка в домике.** Тот же `ftc.fit` по матрице `A_s`, но с
    подбором амплитуд, веса пуассоновские по `y_s`. Напечатать таблицу амплитуд и
    отдельной строкой — отношение каждой свободной амплитуды к соответствующей
    известной (из шага 3), по именам. Заголовок раздела должен прямо говорить, что
    это ДИАГНОСТИКА, а не результат.

В конце `if __name__ == "__main__": main()`.
