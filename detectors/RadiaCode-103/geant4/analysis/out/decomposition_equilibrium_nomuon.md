# Разложение фона с равновесными связями, без мюонной компоненты

**Дата:** 2026-08-28. **Основание:** указание оператора «с учётом знаний о равновесии в
материалах делай новое разложение фона, мюоны не учитывай».

**Постановка.** Спектр естественного фона помещения (RadiaCode-103, CsI(Tl), набор семь суток)
раскладывается по шаблонам Монте-Карло методом наименьших квадратов с ограничением
неотрицательности. В отличие от прежнего расчёта, внутрицепочечные соотношения не подгоняются,
а задаются по справочнику
`skills/geant4-spectrum-pipeline/references/natural-series-equilibrium.md`.

**Команда воспроизведения:**

```
G4MODELS_MEASURED="C:\g4work\measured\RadiaCode-103" G4M_NO_MUON=1 G4M_FIX_RTH=1.0 \
G4M_FIX_FTN=0.0 G4M_FRN_LO=0.10 G4M_FRN_HI=0.10 G4M_FRN_N=1 \
python fit_physical_chains.py
```

## 1. Что задано, а что определялось

| Параметр | Значение | Откуда |
|---|---|---|
| r_Th = A(Th-228)/A(Ra-228) | 1,00 | задан: ряд тория равновесен в природном сырье |
| A(Tl-208)/A(Bi-212) | 0,3594 | задан: ветвление Bi-212, ядерные данные |
| f_Tn (эманирование торона) | 0 | задан: измерения дают 1,2 % для бетона |
| f_Rn (уход радона) | 0,10 | **задан по литературе**, диапазон 0,06–0,15 |
| мюонный шаблон | исключён | указание оператора |
| A(K-40), A(Ra-226), A(Th-232) | определялись | три свободные амплитуды |

Свободных параметров осталось три против девяти в исходной свободной постановке и четырёх в
прежней связанной.

## 2. Результат

| Нуклид | Бк/кг | погрешность |
|---|---|---|
| K-40 | 247,3 | ±7,5 (3,0 %) |
| Ra-226 | 17,5 | ±1,0 (6,0 %) стат. + 1,7 систем. от выбора f_Rn |
| Pb-214, Bi-214 | 15,7 | = A(Ra-226)·(1 − f_Rn) |
| Ra-228, Ac-228, Th-228 | 21,7 | ±0,6 (2,7 %) |
| Pb-212, Bi-212 | 21,7 | равновесие |
| Tl-208 | 7,80 | = 0,3594·A(Bi-212) |

χ²/n.d.f. = 29,23, невязка формы 0,0320, баланс полного счёта 0,999.

## 3. Сравнение с прежним разложением

| Величина | прежнее (мюоны, r_Th подгонялся) | новое | изменение |
|---|---|---|---|
| K-40 | 241,9 | 247,3 | +2 % |
| Ra-226 | 24,2 | 17,5 | **−28 %** |
| Ac-228 | 10,1 | 21,7 | **+115 %** |
| Pb-212 | 20,2 | 21,7 | +7 % |
| Tl-208 | 7,26 | 7,80 | +7 % |
| χ²/n.d.f. | 27,37 | 29,23 | +7 % |

**Главное изменение — ториевая цепочка.** Прежде подгонка давала A(Ac-228) = 10,1 при
A(Pb-212) = 20,2, то есть r_Th = 2,0 на краю сетки. Теперь Ac-228 приравнен к Pb-212 по
равновесию и вырос вдвое, тогда как Pb-212 почти не изменился (+7 %). Это прямое подтверждение
того, о чём предупреждает справочник: Pb-212 и Tl-208 данными определяются надёжно, а Ac-228
(911 и 969 кэВ плечом на комптоновском континууме) — нет, и свободный параметр при нём вбирал
систематику модели, а не измерял сдвиг равновесия.

**Ra-226 упал на 28 %** — следствие того же: подросшая ториевая цепочка забрала часть счёта,
который прежде приписывался урановой.

**Отношение цепочек изменилось качественно:** A(Ac-228)/A(Ra-226) было 0,42, стало 1,24. Для
ограждающих конструкций второе правдоподобнее: у большинства строительных материалов активности
рядов тория и урана сопоставимы, а превышение уранового ряда втрое требовало бы объяснения.

## 4. Почему χ² ухудшился и почему это не аргумент против

χ²/n.d.f. вырос с 27,37 до 29,23. Ухудшение ожидаемо и складывается из двух частей: убран целый
шаблон (мюоны) и снято два свободных параметра. Формальное согласие всегда лучше там, где
параметров больше, но параметр, не имеющий физического смысла, улучшает χ² за счёт поглощения
систематики. Прежнее значение r_Th = 2,0 означало бы химическое разделение радия и тория
несколько лет назад, чего в стене жилого дома не происходит.

## 5. Куда ушли мюоны — по полосам энергии

Отношение модель/измерение:

| Полоса, кэВ | с мюонами | без мюонов |
|---|---|---|
| 20–100 | 0,975 | 0,976 |
| 100–300 | 1,026 | 1,028 |
| 300–700 | 0,977 | 0,976 |
| 700–1500 | 1,007 | 0,971 |
| 1500–2000 | 1,071 | 0,895 |
| 2000–2400 | 1,143 | 0,913 |
| **2400–2830** | 0,959 | **0,438** |

Ниже 700 кэВ разницы нет: мюоны туда почти не дают вклада, и там сосредоточено около 91 %
отсчётов. Выше 1500 кэВ картина меняется: без мюонов модель недобирает 10 %, а в полосе
2400–2830 кэВ — более чем вдвое.

⚠ **ИСПРАВЛЕНО 28.08.2026 (инцидент W-035).** В первой редакции здесь утверждалось, что
«с мюонами в полосах 1500–2400 кэВ был перебор (1,07 и 1,14), то есть мюонный шаблон не просто
закрывал дефицит, а перекрывал его». Утверждение снято как ошибочное: числа 1,07 и 1,14 взяты
из постановки со СВОБОДНЫМ r_Th, севшим на 2,0, и сопоставлялись с числами настоящего отчёта,
где r_Th закреплён единицей. Между сравниваемыми расчётами различались два условия, а разница
отнесена к одному.

При сравнении, где отличие только в наличии мюонного столбца (r_Th = 1,00, f_Rn = 0,10,
f_Tn = 0), мюоны согласие УЛУЧШАЮТ во всех полосах выше 1500 кэВ:

| полоса, кэВ | с мюонами | без мюонов |
|---|---|---|
| 1500-2000 | 0,997 | 0,895 |
| 2000-2400 | 1,070 | 0,913 |
| 2400-2830 | 0,973 | 0,438 |
| chi2/ndf | 28,175 | 29,234 |

Оставшиеся +7 % в полосе 2000-2400 приходятся на ториевую цепочку (0,00454 с⁻¹ из 0,00697 с⁻¹
модели, то есть 65 %), а не на мюоны (0,00183 с⁻¹). Действующая постановка страницы — С
мюонами; настоящий отчёт сохранён как описание расчёта без них.

## 6. Чувствительность к принятому f_Rn

| f_Rn | A(Ra-226), Бк/кг | χ²/n.d.f. |
|---|---|---|
| 0,00 | 15,80 | 29,218 |
| 0,06 | 16,77 | 29,227 |
| 0,10 | 17,49 | 29,234 |
| 0,15 | 18,46 | 29,244 |

χ² меняется на 0,03 % на всём литературном окне — **параметр данными не определяется**, что и
было предсказано справочником. При сканировании 0–0,30 оптимум ложится на нижний край, а профиль
покрывает весь диапазон.

Практический вывод: A(Ra-226) нельзя привести без указания принятого f_Rn. По литературному окну
0,06–0,15 размах составляет 1,7 Бк/кг, то есть 10 % — это систематическая составляющая
неопределённости, сравнимая со статистической.

## 7. Ограничения

- Мюонная компонента исключена по указанию оператора; полоса выше 2400 кэВ поэтому недобирается
  более чем вдвое, и результаты в ней интерпретации не подлежат.
- f_Rn принят по литературе, а не измерен на этом материале. IAEA TRS-474 требует измерять
  коэффициент эманирования для каждого материала.
- r_Th = 1,00 обоснован механизмом (разделение радия и тория требует химического передела) и
  данными по почвам и породам; прямых измерений на строительных материалах в литературе нет.
- χ²/n.d.f. ≈ 29 означает, что модель отклика описывает форму спектра не полностью. Причина
  лежит вне равновесных связей и не устраняется их уточнением.
