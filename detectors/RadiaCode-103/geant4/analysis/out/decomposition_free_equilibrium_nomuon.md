# Разложение фона без мюонов при свободном равновесии

**Дата:** 2026-08-28. **Основание:** указание оператора «сделай подгонку без мюонов
и без фиксированного равновесия, равновесие пересчитай по факту».

**Постановка.** Мюонный шаблон исключён. Параметры равновесия r_Th = A(Th-228)/A(Ra-228),
f_Rn (уход радона) и f_Tn (эманирование торона) не задаются, а определяются сканированием
сетки. Ветвление A(Tl-208)/A(Bi-212) = 0,3594 остаётся структурной константой ядерных
данных и параметром подгонки не является.

**Команды воспроизведения:**

```
G4MODELS_MEASURED="C:\g4work\measured\RadiaCode-103" G4M_NO_MUON=1 python fit_physical_chains.py
G4MODELS_MEASURED="C:\g4work\measured\RadiaCode-103" G4M_NO_MUON=1 \
  G4M_RTH_LO=0.5 G4M_RTH_HI=10.0 G4M_RTH_N=96 python fit_physical_chains.py
```

## 4. Почему результат нефизичен

r_Th = 8,3 означает, что торий-228 в восемь раз превышает радий-228, из которого он
образуется. Такое состояние требует почти полного удаления Ra-228 из материала за срок
порядка периода полураспада Th-228, то есть химического передела в течение последних лет.
Одновременно f_Rn = 0 требует, чтобы из того же материала не уходил даже радон. Два
условия противоречат друг другу.

Направление ухода параметров одинаково: подгонка увеличивает вклад компонент, наблюдаемых
по ярким изолированным линиям (Pb-212 238,6 кэВ; Tl-208 583,2 и 2614,5 кэВ; Bi-214 609,3
кэВ), и обнуляет компоненту, наблюдаемую по слабо разрешённому плечу (Ac-228 911,2 и
968,9 кэВ на комптоновском континууме).

## 5. Требует толкования (по блоку самопроверки скрипта)

- **f_Rn на нижнем крае в обоих прогонах.** Уход радона данными не ограничивается;
  ранее показано, что chi2 на литературном окне 0,06–0,15 меняется на 0,03 %.
- **r_Th упирался в край, пока край не отодвинули.** После отодвигания оптимум ушёл
  следом — признак вырожденности, а не смещённого оптимума.
- **chi2/ndf около 27.** Модель формально отвергается целиком. В этом режиме сравнение
  постановок по приросту chi2 некорректно: разницу определяют систематические отклонения
  формы, а не статистика. Поэтому 27,46 против 29,22 при заданном равновесии доводом
  в пользу свободной постановки не является.
- **Ac-228 и мягкая часть.** Гипотеза о причине: кривая разрешения завышает ширину линий
  на 13–15 % в области 900–1500 кэВ (установлено 28.08 сверкой с двумя измерителями),
  и размазанный дублет 911/969 кэВ не воспроизводит наблюдаемое плечо. Не проверено.

## 6. Вывод

Пересчитать равновесие по этим данным нельзя: ни в ториевом, ни в урановом ряду параметры
сдвига не имеют минимума и уходят на границы сетки. Свободная постановка даёт вырожденное
семейство решений, в котором устойчив только нижний сегмент ториевой цепочки:
Pb-212 = Bi-212 = 25,0 Бк/кг, Tl-208 = 8,98 Бк/кг. Активности Ra-226, Ac-228 и K-40
зависят от того, где остановить сканирование, и приводиться без указания принятого
r_Th не могут.
