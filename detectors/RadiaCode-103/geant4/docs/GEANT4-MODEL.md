# Geant4-модель RadiaCode-103

Комплект геометрии RC-103 для Monte Carlo (Geant4): корпус-envelope (примитив,
без STL), электроника, детектор.

**Обновлено 2026-08-26:** GDML впервые провалидирован штатным парсером Geant4
(`C:\geant4-gdml`, GDML-модуль появился в проекте в этот же день). Найден и
исправлен самоссылающийся материал `G4_Si` (P-001, `../audit/project-incidents.md`)
— до этой правки файл ни разу не проходил штатный парсер. После фикса прогнан
`G4PVPlacement::CheckOverlaps()` по всем physvol — результат и точные величины
протрузий см. «Ограничения модели» ниже.

**Состав этого репозитория — только то, что реально написано/сгенерировано и
проверено ЗАПУСКОМ в этой сессии** (по прямому требованию оператора 26.08.2026:
«нужно оставить только твоё и проверенное», затем «оставить только твой
комплект, всё лишнее удалить»). Референсная папка оператора
(`D:\GoogleDrive\Дозиметрия\Спектры\RC103\geant4\`, локальная, вне репозитория)

## Ограничения модели

Количественно подтверждено `G4PVPlacement::CheckOverlaps()` 26.08.2026 (после фикса
P-001) — величина протрузии для каждого пункта, не только качественное описание:

- Корпус-envelope: bbox-примитив без STL-формы; без USB-выреза (`USB_log` протыкает
  `Case_interior_log` на **1.75 мм** по +X, и наружную грань корпуса — на **250 мкм**,
  физически ожидаемо, разъём и должен торчать наружу), без окна в ABS
  (`Display_window_log` протыкает на **1.3 мм**, `Display_LCD_log` — на **600 мкм**,
  обе по −Z: узлы дисплея физически лежат в толще передней стенки, вырез не
  смоделирован).
- Капсула: box вместо rounded-square 16×16 fillet R≈5; ниша SiPM Ø11×2.2мм не
  смоделирована → `SiPM_log` протыкает капсульную полость на **400 мкм**,
  `SiPM_carrier_log` протыкает стенку капсулы на **425 мкм** (оба — прямое следствие
  отсутствия ниши).
- PCB: монолитный бокс без U-cutout (как RC-110) → пересекается с капсульным узлом на
  **485 мкм**.
- EMI-ткань: номинальный box даёт край **50 мкм** за границу полости (мелкое реальное
  превышение, не опечатка).
- ESR-плёнка (5 граней, каждая на 0.065 мм шире грани кристалла — умышленный нахлёст
  под light-tightness) слегка перекрывается сама с собой в углах куба: **12-32 мкм**.
- Материалы LiPo/LCD/USB/EMI — упрощённые смеси.

Все величины и полная таблица классификации (фон/малый артефакт) —
`../audit/project-incidents.md`, раздел «Overlap-валидация». Ни одна протрузия не
потребовала правки координат: все либо прямое следствие уже перечисленных упрощений
примитивов, либо суб-100-микронный артефакт построения ESR/EMI.
