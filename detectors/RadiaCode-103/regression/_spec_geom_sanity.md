# Спека: geom_sanity_check.py

Скрипт-шлюз §34-петли «response-geometry-sanity-radiacode103» контура GEANT4.
Файл создаётся в папке `regression/` (той же, где уже лежит `regression_check.py`,
`ref_cs137.mac`, `ref_k40.mac`, `baseline.json`).

## Назначение

В отличие от уже существующей петли `regression-physics-radiacode103`
(`regression_check.py` — ловит НЕЖДАННОЕ изменение физики на НЕИЗМЕННОЙ
геометрии, сравнивая с зафиксированным baseline), эта петля решает обратную
задачу: после НАМЕРЕННОЙ правки геометрии детектора (`RCDetector.cc`/`.hh`)
проверить, что кристалл всё ещё физически вменяемо откликается на
моноэнергетические гамма-кванты — БЕЗ сравнения с прошлым значением (оно
законно меняется вместе с геометрией).

## Обязательное переиспользование (ступень −1a, не писать заново)

В начале файла добавить в `sys.path` папку самого скрипта (`os.path.dirname
(os.path.abspath(__file__))`) и импортировать из уже существующего
`regression_check.py`, лежащего в той же папке:

```python
from regression_check import run_macro, EXE, GEANT4_ENV
```

`run_macro(macro_name)` уже делает всё нужное: собирает окружение Geant4,
запускает `EXE` (`rc_curves.exe`) с макросом и режимом `"bare"`, парсит
`hits=\s*(\d+)` из stdout, поднимает `RuntimeError` при ошибке запуска или
ненулевом коде возврата, или если строка `hits=` не найдена. НЕ дублировать
эту логику — импортировать как есть.

## Логика main()

1. Функция `geometry_hash()` — SHA1 (модуль `hashlib`) от конкатенации БАЙТОВОГО
   содержимого обоих файлов из `GEOM_FILES` (открывать в режиме `"rb"`), вернуть
   `hexdigest()[:12]` (короткая строка для читаемости в state).

2. Путь состояния: `STATE_PATH = Path(__file__).parent / "geom_sanity_state.json"`.

3. Разбор аргументов: флаг `--force` в `sys.argv` — принудительно прогнать
   sanity, даже если хеш геометрии не изменился с последнего успешного (`OK`)
   прогона.

4. Чтение прежнего состояния (если файла нет — считать, что прогона раньше не
   было, действовать как при изменившемся хеше). Прежнее состояние — JSON вида
   `{"geometry_hash": "...", "overall": "OK"/"FAIL", "checked_at": "...",
   "details": [...]}`.

5. Если текущий `geometry_hash()` СОВПАДАЕТ с сохранённым `geometry_hash` в
   состоянии И прежний `overall == "OK"` И флаг `--force` не передан —
   печатать `"АКТУАЛЬНО: геометрия не менялась с последней успешной проверки
   (%s), sanity-прогон пропущен" % hash` и завершиться `sys.exit(0)` НЕМЕДЛЕННО,
   не запуская ни один макрос (это и есть дешёвая часть петли — доли секунды).

6. Иначе (хеш изменился, либо прежнего OK не было, либо `--force`) — прогнать
   ВСЕ 4 точки из `SANITY_REFS` по очереди (не параллельно — макросы уже
   быстрые, 30000 событий каждый):
   - для каждой точки вызвать `run_macro(ref["macro"])`;
   - если `run_macro` подняла `RuntimeError` — считать эту точку `"FAIL"` с
     полем `"error": str(e)` в её записи результата, НЕ прерывать цикл (собрать
     статус по всем 4 точкам, даже если одна упала);
   - если `hits` получен успешно — статус `"OK"`, если `MIN_HITS <= hits <=
     MAX_HITS`, иначе `"FAIL"` с полем `"hits": hits`;
   - печатать построчно по каждой точке: `"  %-8s E=%8.1f кэВ  hits=%-8s ->
     %s" % (name, e_kev, hits_or_dash, status)` (если hits нет из-за ошибки —
     подставить прочерк `"-"`).

7. `overall = "FAIL"` если хотя бы одна точка `"FAIL"`, иначе `"OK"`.

8. Записать новое состояние в `STATE_PATH` (JSON, `ensure_ascii=False,
   indent=2`): `geometry_hash` (текущий), `checked_at` (`time.strftime("%Y-%m-%d
   %H:%M:%S")`), `overall`, `details` (список словарей по каждой точке: `name`,
   `e_kev`, `hits` (или `None`), `status`, и `error`, если была ошибка).

9. Если `overall == "FAIL"` — печатать `"SANITY FAIL: геометрия правлена
   (RCDetector.cc/.hh), но отклик детектора на %d из %d контрольных энергий не
   проходит проверку вменяемости — см. geom_sanity_state.json"` (подставить
   число FAIL и всего точек), `sys.exit(1)`.

10. Если `overall == "OK"` — печатать `"SANITY OK: геометрия физически
    вменяема на всех %d контрольных энергиях (hash=%s). НАПОМИНАНИЕ: это НЕ
    заменяет полный производственный пересчёт results/bare/response/resp_*.csv
    (28 точек, ручное действие, см. DECISIONS.md D-002) — та сетка используется
    в подгонке (anchor_lines.py) и должна быть пересчитана вручную при
    значимой правке геометрии." % (число точек, hash)`, `sys.exit(0)`.

## Технические требования

- В начале файла: `sys.stdout.reconfigure(encoding="utf-8")` (кириллица в
  выводе на Windows-консоли, как уже сделано в `regression_check.py`).
- Docstring модуля (2-4 предложения): что делает скрипт, чем отличается от
  `regression_check.py`, ссылка на карточку `audit/loops.md`.
- Только стандартная библиотека (`sys`, `os`, `re` не нужен — `run_macro`
  уже импортирован, `json`, `hashlib`, `time`, `pathlib.Path`).
- `if __name__ == "__main__": main()`.
- НЕ читать содержимое `.mac`-файлов, НЕ проверять их наличие явно — ошибка
  открытия файла макроса всплывёт из `run_macro`/`subprocess` естественным
  образом и будет поймана как `RuntimeError` в шаге 6.
