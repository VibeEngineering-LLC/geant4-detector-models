# RadiaCode-110 — геометрия для Geant4

Комплект геометрии RC-110: полый корпус-примитив либо тесселированный
STL-корпус, электроника (плата, LiPo, дисплей, USB) и детекторный узел
(CsI(Tl) 14³ + SiPM + ESR в капсуле).

Полное описание модели, системы координат и провенанса чисел —
[`geant4/docs/GEANT4-MODEL.md`](geant4/docs/GEANT4-MODEL.md).

## Что здесь есть и чего нет

| Есть | Где |
|---|---|
| SSOT-геометрия (все внутренности + корпус-примитив) | `geant4/gdml/detector/RC110_detector.gdml` |
| Генератор тесселированных GDML из STL | `geant4/scripts/stl_to_gdml.py` |
| C++ загрузчик STL через CADMesh | `geant4/cadmesh/` |
| Картинка совмещения корпус/внутренности | `geant4/verify/RC110_align_check.png` |

**Намеренно НЕ в репозитории** (восстанавливается из исходников, суммарно ~56 МБ):

- `gdml/full/RC110_full.gdml` и `gdml/case_mesh/RC110_case_mesh.gdml` —
  генерируются `stl_to_gdml.py` из `Rc-110.stl`;
- `Rc-110.stl` (5,5 МБ, 110 666 треугольников) и `RC110_model.blend` —
  исходники в референсной папке оператора, вне репозитория.

Так же, как в этом репозитории не коммитятся расчётные спектры и сборка
(см. корневой `.gitignore`).

## Статус: геометрические дефекты закрыты (26.08)

Три найденных дефекта («дочерний объём торчит из материнского» — капсула
выходила за контейнер на 0,35 мм по +X; SiPM выходил за полость капсулы
на 0,3 мм по −Z; смещение узла терялось при экспорте) и расхождение
ESR↔модель (грани −Z у отражателя не было вовсе, окно 6,4×6,4 под SiPM
отсутствовало) **исправлены и проверены арифметикой/независимым
пересчётом по файлу**, детали — `geant4/docs/GEANT4-MODEL.md` и
`SESSION-STATE.md` контура (локально). Плата, аккумулятор, дисплей и
USB уже смоделированы (таблица внутренних узлов — `geant4/docs/GEANT4-MODEL.md`).

Не смоделированы отдельные SMD на плате (сознательное упрощение,
решение оператора) и скругления/USB-вырез корпуса-примитива.

Дополнительно из `docs/GEANT4-MODEL.md`: в `gdml/full/` STL-корпус —
сплошное тело, и с внутренностями он пересекается по построению; для
физики предназначен вариант с корпусом-примитивом.

## Ограничение платформы

GDML-модуль **отсутствует** в установленной здесь сборке Geant4 11.2.1
(prebuilt CERN, без Xerces-C): нет ни `G4GDMLParser.hh`, ни `G4gdml`.
Пока Geant4 не пересобран с `GEANT4_USE_GDML=ON`, эти файлы нельзя
загрузить штатным парсером на данной машине — ни для расчёта, ни для
визуализации.
