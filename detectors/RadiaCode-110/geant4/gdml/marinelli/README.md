# Маринелли RC-110 в сборе — GDML

Сосуды Маринелли под RadiaCode-110 трёх размеров: M120, M200, M380. Каждый сосуд — банка и навинченная крышка. Печатаются из PETG.

| файл | банка, треугольников | крышка, треугольников | объём PETG банки / крышки, мм³ |
|---|---|---|---|
| `RC110_marinelli_M120.gdml` | 49 638 | 11 922 | 55 264,1 / 15 252,5 |
| `RC110_marinelli_M200.gdml` | 61 152 | 11 928 | 66 394,8 / 15 259,7 |
| `RC110_marinelli_M380.gdml` | 44 492 | 11 606 | 115 145,7 / 26 484,9 |

## Форма
Форма взята из STL автора без упрощения. Каждый треугольник STL становится гранью `G4TessellatedSolid`, порядок вершин в грани сохранён. Над вершинами выполняются только повороты и сдвиги. Резьба горловины и крышки сохранена полностью.

## Сборка
- Крышка навинчена до упора: внутренняя грань диска крышки лежит на торце горловины.
- Угол поворота крышки задаёт фазу резьбы. Он выбран так, чтобы объём, общий для банки и крышки, был минимальным. Перебор шёл с шагом 5°, объём считался по сечениям через 0,1 мм.
  - При выбранном угле общий объём равен 0 мм³.
  - При худшем угле он составляет 144 мм³ (M120, M200) и 223 мм³ (M380).
  - Нулевые углы повторяются через 120°, потому что резьба трёхзаходная.
- Крышка отведена от банки на 1 мкм по оси. Без этого витки и торец, которые касаются друг друга, после округления координат до 1 нм дают в проверке Geant4 перекрытие глубиной 2 нм. Отвод на 1 мкм перекрытие снимает, отвод в обратную сторону его углубляет до 1 мкм (проверено на M200).
- В файле два тома PETG, каждый — отдельный `physvol` в мире: `Marinelli_<размер>_Can` и `Marinelli_<размер>_Cap`. Мир заполнен воздухом.

## Система координат
- Рабочее положение: сосуд стоит крышкой вниз, колодец открыт вверх.
- Начало координат лежит на оси, на внутренней поверхности дна колодца, куда упирается торец прибора. Ось +Z направлена вверх.
- Единицы — мм.
- Проба (полость между колодцем, стенкой и крышкой) в файл не входит: её задаёт пользователь своим материалом.
- Ось RC-110 в `gdml/detector/RC110_detector.gdml` направлена иначе. При совмещении прибор нужно повернуть так, чтобы его ось совпала с +Z этого файла.

## Материал
PETG = C₁₀H₈O₄ (звено ПЭТ), ρ = 1,27 г/см³. Это допущение: плотность литого материала, заполнение при печати не учтено.

## Проверка
- `G4GDMLParser` (Geant4 11.2.1) читает файл. У обоих тел материал PETG и тип `G4TessellatedSolid`. Объёмы, которые считает Geant4, совпадают с объёмами по STL (trimesh) в пределах 0,05 мм³.
- `G4PVPlacement::CheckOverlaps` для банки и крышки всех трёх размеров выдаёт OK.

## Как получено
Генератор — `geant4/scripts/marinelli_gdml.py <can.stl> <cap.stl> <размер> <out_dir>`, сечение для проверки — `geant4/scripts/gdml_section.py` (`section_all.png`). Рядом с каждым GDML лежит JSON с параметрами сборки и перебором угла.
