# ЗАКОН МЕТОДА — разложение гамма-спектров на модели детектора

Общий для всех детекторов репозитория. Специфика конкретного прибора (геометрии, референсы, опоры, числа паспортов, состояние
критериев) — в приложении в папке детектора, например `detectors/Atom-GS2020-PRO-MAX/method/README.md`. Связанные документы:
`PHYSICS.md` (слои отклика), `STAGES.md` (этапы метода с планами проверки, коррекции, оптимизации и аудита).

Статус: закон заморожен 31.10.2026 владельцем метода (в тексте закона — «оператор»). Правка — только по его слову в исключительном случае, строкой в журнале правок (дата, причина, слово). Раздел 1 ниже —
дословно действующая редакция принципа и пунктов закона; журнал правок с причинами ведётся в приложении детектора, на котором закон
принят (`detectors/Atom-GS2020-PRO-MAX/method/README.md`, раздел 7). Слова «относительно воды» в п.3 — по этому прибору (вода — его
проба-эталон фона); для другого детектора читаются как «относительно его пробы-эталона фона».

## 1. Закон

**Принцип (оператор, 31.10.2026, дословно):** «подгонка под спектр недопустима. есть модель прибора и источника. есть методы. все
спектры снятые в этой геометрии должны эффективно раскладываться при помощи метода».

1. **Ответ — функция трёх вещей:** набор прибора D (заморожен), геометрия G (задана, не подбирается; G — сосуд, их может
   быть несколько; D общий, перенос референса из его G в G пробы — расчётом МК по GDML обоих сосудов), вход измерения M (то, что
   сообщают файл спектра и паспорт пробы). Свободны в подгонке только амплитуды нуклидов/цепочек, a_k ≥ 0, по одной на позицию
   списка нуклидов M. **Список фиксируется до подгонки** и печатается в лог; добавление нуклида по
   результату подгонки (χ², остаток) запрещено. Больше — ничего.
2. **Законно различается между спектрами только M:** шкала энергии спектра — **привязка по его собственным реперным пикам**
   (#CAL-0) при форме полинома, наборе групп и регуляризации из D, одинаковых для всех спектров; шкала из файла — только начальное
   приближение; если ПОСЛЕ привязки невязка репера >0,25·ПШПВ — отказ, не подбор формы; живое время; спектр фона той же геометрии;
   паспорт пробы — плотность, состав, масса, уровень; список искомых нуклидов.
3. **Всё остальное — свойство прибора в этой геометрии** и берётся из D, заданного один раз по референсу (#DET-1): геометрия,
   перенос, свет (непропорциональность — включена всегда), светосбор, тракт и форма шкалы, ширина и форма пика, порог и рампа
   регистрации, собственные линии, поправки самопоглощения и ослабления фона по плотности и составу относительно воды.
3а. **Библиотека метода** — ядерные данные одной базой.
4. **Ручка, выбираемая по результату подгонки конкретного спектра** (файл шкалы, узел, хвост, множитель ширины, вариант фона,
   окно, вес, «долив» физики для одной пробы, тег варианта), — дефект метода. Каждая либо становится константой D, либо
   вычисляется из D·G·M, либо удаляется; возникла она потому, что в D недостаёт слоя, — удаление ручки и достройка слоя идут вместе.
5. **D меняется только по референсу и версией** (sha карточки в каждом логе), никогда по результату пробы.
6. **Доверие — сходимостью:** один код, один конфиг, один D → все пробы проходят одни и те же критерии §3; оба метода (М1 и М2)
   на одном D печатают ответ и расхождение.

Метки в пунктах: **#CAL-0** — шкала энергии своя у каждого спектра, проверяется по его реперным линиям; **#DET-1** — характеристики
детектора (ширина и форма пика, разрешение, эффективность) определяются по референсным спектрам один раз и дальше переносятся.

## 2. Термины

- **D** — набор прибора: замороженные таблицы и константы (геометрия прибора, матрица отклика или шаблоны, ПШПВ(E) и форма пика,
  параметры света, светосбор, тракт, порог и рампа, собственные линии, схемы поправок пробы, константы метода), карточка с sha всех
  файлов. Строится один раз по референсу; меняется только новой версией.
- **G** — геометрия измерения: сосуд и уровень заполнения. Задана, не подбирается. Геометрия самого прибора — часть D. Если референс
  снят в другой G, чем пробы, — перенос расчётом МК по моделям обоих сосудов. Уровень сообщает паспорт пробы (M), а определяет он
  G: другой уровень — другая G, с МК-переносом.
- **M** — вход измерения: спектр пробы и его живое время, спектр фона той же G, паспорт пробы (масса, объём, плотность, состав,
  уровень, дата), список нуклидов (задаётся до подгонки). **Карточка пробы** — файл M с этими полями; sha — в лог до подгонки.
- **Референс** — спектр источника с паспортом, по которому строится D; назван в приложении детектора до построения D.
- **М1 / М2** — два метода на одном D: М1 — МК-шаблоны цепочек нуклидов; М2 — матрица отклика D × библиотека линий.
- **Подгонка** — только разложение спектра на амплитуды a_k ≥ 0. **Привязка шкалы** по реперам спектра — этап входа M, подгонкой в
  смысле закона не является; её форма — из D.
- **Пререгистрация** — набор вариантов D, пороги и правила критериев, список нуклидов и правило провала записаны коммитом до счёта;
  sha этого коммита печатается в логе счёта. Запись после просмотра результата пререгистрацией не является.
- **Реестр версий D** — тег git версии D и файл со списком sha всех таблиц карточки; sha в логе сверяется с реестром, не с полем
  внутри той же карточки.
- **Окно** — диапазон энергий оценки мер, константа D, одна для всех проб; выбирается при построении D, не по невязке пробы. Дефект
  п.4 — выбор окна под пробу; само окно как константа дефектом не является. Изменение окна — новая версия D для всех проб. Пока окно
  уже рабочего диапазона прибора, область вне окна критериями К1–К2 не проверяется — это долг метода, записанный в приложении.
- **k** — множитель спектра фона при вычитании сверх нормировки на живое время: фон × (живое время пробы / живое время фона) × k,
  k = 1,00 — константа метода. Ослабление фона пробой — отдельная расчётная функция r(E), не часть k.
- **r(E)** — отношение внешнего фона под пробой к фону под пробой-эталоном фона, функция энергии; вычисляется из плотности и состава
  пробы. Применяется к внешней части фона; собственный фон прибора — без ослабления.
- **Вес model** — дисперсия канала в χ² по модели (σ²_i = m_i, χ² Пирсона), не по измерению.
- **Нуль-база (C0)** — реплики спектра, разыгранные из модели: разброс мер при верной модели.
- **Конверт систематики (C2)** — корень из суммы квадратов откликов активности на возмущения из закрытого списка D (сдвиг и
  растяжение шкалы, ширина, фон, r(E), континуум). Размеры возмущений — измеренные, то есть взятые из данных референса и фона, а не
  из плана и не из невязки самой пробы. На пробу с другим отношением сигнал/фон S/B конверт переносится только пересчётом (вклад
  фона растёт ∝ B/S).
- **Континуум** — гладкая часть модели между пиками (комптон, тормозное, рассеяние).

## 3. Критерии «спектр разложен эффективно»

Критерии (оператор, 31.10.2026, дословно): «минимум невязки по форме и χ²/ntd (если не ошибся с буквами) и совпадение удельной
активности с паспортами» (χ²/ntd = χ²/ν).

Одинаковы для всех спектров. Правило порога одно для всех (квантиль q нуль-распределения C0, число реплик — заранее), число порога —
своё у спектра из его счёта; правило пререгистрируется до счёта. Печатаются одной строкой на спектр, считаются одним кодом.
- **К1. Форма** — две меры с разными порогами: (1) невязка формы ½Σ|p/Σp − m/Σm| по окну — безразмерная доля (в процентах —
  50·Σ|…|), печатается рядом со своим нижним пределом от статистики; (2) `ФОРМА ПИКОВ` — χ²/ν в окнах ±1,5 ПШПВ вокруг опорных пиков
  (список опорных пиков — в D). Минимум по вариантам — только при построении D по референсу, на пререгистрированном наборе,
  одинаково для всех проб; для отдельного спектра К1 — порог, не оптимизация.
- **К2. χ²/ν** по окну при весе model; порог — из нуль-базы C0.
- **К3. Удельная активность против паспорта:** |A/A_пасп − 1| внутри конверта C2. Расчётный паспорт (например, по массе соли)
  считается той же библиотекой ядерных данных; аттестованный паспорт источника берётся с его неопределённостью; бюджет
  неопределённости паспорта выписывается. Где паспорта нет, К3 не применим: такой спектр записывается «К1, К2 пройдены, К3 не
  применим», а не «К1–К3 пройдены», и активность не проверяет. Референс для К3 — замыкание, не проверка.
- Все три — одновременно: проход по К3 при провале К1 — провал.
- **А1** один код, одна конфигурация без ключей по пробам (sha в каждом логе; схема конфига проверяется; окно одно и записано в конфиге).
- **А2** все спектры проходят К1–К3 (К3 — где применим) по одному правилу порогов.
- **А3** М1 и М2 на одном D сходятся в пределах C2 (конверт D, общий для обоих методов) для каждого нуклида. Согласие необходимо, не достаточно: ошибки D у методов общие.
  Расхождение выше конверта — сигнал неполноты D или физики, не повод выбирать метод.
- **А4** слепая проба: спектр той же G, не участвовавший ни в построении D, ни в настройке, с паспортом (К3 применим), проходит А2
  без изменения конфигурации. Пороги, список нуклидов и правило провала — коммитом до выдачи активности. Цель — не меньше трёх
  слепых спектров: один спектр слабо различает гипотезы.
- **А5** D побайтно один во всех подгонках (sha против реестра версий D). Что D не настраивался по пробам до заморозки, А5 не
  доказывает — это матрица К1 (STAGES, Э1) и А4.
- **А6** полнота физики D: 0 слоёв «не учтено» без задачи (`PHYSICS.md`; «не учтено» — статусы «нет» и «не проверено»). К1–К3
  физически неполную модель не отсекают.
- Пока А4 не выполнен или в D есть слой «не учтено» (даже с задачей), метод для данного детектора унифицированным не называется.

## 4. Как детектор подключается к закону

Приложение детектора содержит: G (сосуды, модели), референс и роли спектров (референс / проверка / пробы), опоры шкалы и порога,
паспорта и их неопределённость, карточку D с sha, состояние слоёв `PHYSICS.md`, действующее состояние критериев (числа, что не
выполнено), журнал правок закона. Закон, термины и критерии в приложении не переопределяются.

Источник: рабочие документы авторов метода (не опубликованы) — закон (принцип и пункты, дословно), термины, контракт, критерии и
решения владельца метода (обобщены без чисел прибора).
