## 2. Независимый перечень значимого (источники)

* Состав поля PARMA (Sato 2015, PLOS ONE 10(12):e0144679, раздел «General Description of PARMA3.0»): n, p, ионы до Ni, μ, e⁻, e⁺, γ; пионов нет; диапазон 10 кэВ–1 ТэВ (n — от 0,01 эВ).
* Угловая модель (Sato 2016, PLOS ONE 11(8):e0160390): n, p, He, μ±, e±, γ; сказано «more experimental data will therefore be necessary to validate ... electron, positron, and photon fluxes»; параметр g = «water density in the ground or aircraft mass».
* `parma\Readme.txt` Q6 (строки 76-89): g = 10 — идеальная атмосфера без окружения; −10<g<0 — самолёт, «только нейтронный спектр меняется».
* Бортовые нейтроны: почти нет тепловых в свободном воздухе, пик испарения ~1 МэВ и второй ~100 МэВ (Goldhagen и др., NIM A 476 (2002) 42; RPD 110 (2004) 387 — по аннотациям; полный текст не читал).
* Geant4 (Physics List Guide 11.4, FTFP_BERT): списки без HP не имеют захвата <20 МэВ; в _HP «radioactive decay is activated». Option4: Monash-Комптон <20 МэВ, Livermore фото/Рэлей, флуоресценция по умолчанию, Оже и PIXE — нет.
* Собственный фон CsI: измерены Cs-137, ряды U/Th (arXiv:1408.0590, KIMS-CsI; числа в доступной части не получил); космогенные в кристаллах типа NaI/CsI: ¹²⁵I, ¹²¹Te, ¹²¹ᵐTe, ¹²³ᵐTe, ¹²⁵ᵐTe, ¹²⁷ᵐTe, ¹¹³Sn, ¹⁰⁹Cd, ³H, ²²Na (COSINE-100, arXiv:1905.12861 — по поисковой выдаче).
* K-40 в теле: UNSCEAR 2000 Annex B (0,18 % K, 54,8 Бк/кг — по `research/B §6.1`, дословно не перепроверял).
* Вторичные источники внутри проекта (используются как указатели, не как проверенные факты): `research/A §2.4-2.5, §6.3`, `research/B §5-6, §10`, `research/C §2.3-2.8` (в них — Roy A., Sarkar R., Lee C., arXiv:2112.07911, Табл. 1 и 3; PDF мной не открылся, значения пересказом).

## 3. Расхождения

Обозначения: [НЕТ] — в модели отсутствует; [ЛИШНЕЕ/НЕВЕРНО] — включено неверно или противоречит документам; [ПРОВЕРИТЬ] — подозрение, требующее прогона.

### 3.1 Источник

1. **[НЕТ] Ионы He–Ni первичного поля.** Таблицы строятся только для ip 0,1,29–33 (`parma_tables.cpp:24`), CFG-1 п. 3.6. Вклад: по `research/A §2.4` (своя свёртка проекта, Москва 11 км, W 11,1) ионы = 1,7 % эффективной дозы; для спектра 20 кэВ–10 МэВ, Rc 17 ГВ, 9,8 км — не нашёл. Первичные ионы дают в кристалле >10 МэВ (вне диапазона); вклад в диапазон идёт через фрагменты в конструкции — порядок не нашёл.
2. **[НЕТ] Пионы, каоны.** PARMA их не выдаёт (Sato 2015). Вклад в дозу 0,15 % (Roy и др., Табл. 1, через `research/A §2.5`; не перепроверено). π⁰-распад в конструкции — через адронную физику от p, n, μ.
3. **[ПРОВЕРИТЬ] Первичные вне мира Geant4 — потеря нормировки.** Мир — куб ±560 см (`cabin_geom.hh:93`), диск источника R = 480 см стоит на расстоянии 480 см (`cabin_stage1.cc:39`; `parma_source.hh:209-224`); точки старта уходят до 679 см от центра. Расчёт аудитора (Монте-Карло 20 угловых бинов × 40 000 лучей по геометрии кода, веса — угловые маргиналы таблиц `tables/dadsgn/w76_h98_ip*.tab`): 18 % стартовых точек лежат вне куба; среди лучей, попадающих в фюзеляж-сектор, вне мира стартует 7,6–8,0 % (n 7,95 %, p 7,78 %, γ 7,88 %, e⁻ 7,95 %, μ⁺ 7,59 %). Судьбу первичного вне мира в Geant4 не проверял; предупреждений в логах нет (в `results/stage1/prod2/*.log` только Run0111). Если трек молча убивается — недоучёт всех компонент ≈ 8 % (одинаков для всех, поэтому самопроверки `audit_tsim.sh` и весов его не ловят). Замыкающий тест (`CABIN_EMPTY` + `CABIN_DIRECT`) в SESSION-STATE отмечен как не сделанный. Лечение (не выполнено, файлы не правил): мир ≥ 680 см либо диск не в касательной плоскости.
4. **[ЛИШНЕЕ/слабое место] Фотоны и e± PARMA — главный вклад в счёт и наименее проверенная часть.** По пилоту γ ≈ 52 из ≈ 62 отсч./с (`SESSION-STATE.md`, строка про pilot1). Sato 2016 прямо пишет о недостатке измерений для e±, γ; Sato 2015 сверяет с расчётом PHITS-EAS (R² 0,983–0,992 по `research/A §4.1`), а не с бортовым измерением. Измерений спектра γ 10–100 кэВ на эшелоне не нашёл (`research/B §10 п. 5` — то же). Абсолютная погрешность: не нашёл.
5. **[ЛИШНЕЕ, малое] Обрезка на 100 ГэВ** при заявленных Sato 2015 1 ТэВ (`parma_tables.cpp:46`). Для диапазона ≤10 МэВ вклад пренебрежимый по физике (высокие энергии дают MIP-события >10 МэВ); оценки по источнику нет.
6. **[ПРОВЕРИТЬ] g = 10 (без окружения)** — по Readme Q6 верно для явной модели фюзеляжа; но альбедо Земли и «геофактор» для нейтронов в этом режиме заданы моделью PARMA, а не расчётом. Влияние на 20 кэВ–10 МэВ: не нашёл.

### 3.2 Геометрия и материалы (этап I)

7. **[НЕТ] Крылья, топливо, двигатели, оперение, кабина экипажа, стойки шасси.** В `cabin_geom.hh` только цилиндр ±4 м; CFG-1 п. 11 — «топлива под сектором нет». По `research/A §6.3` (пересказ Roy и др., Табл. 3): под днищем с баком поток γ вверх −88 %, n вверх −87 %, вниз n +14 %, γ +27 % на середине — то есть направление и величина зависят от сценария. Место у окна: крыло и его баки рядом; вклад — не нашёл (нужен прогон).
8. **[НЕТ] Внутренний интерьер как отдельные тела.** Кресла, полки, панели, окна, контейнеры багажа — эквиваленты по массе (`cabin_geom.hh:29-33`). По `research/C §2.3` (777, aircraftinvestigation.info, не проверено): интерьер ≈ 9,9 т; кресло 5,8 кг. Значимо локально для Al-линий захвата и водорода вблизи прибора; порядок — не нашёл.
9. **[ЛИШНЕЕ/упрощение] Пустая трубка R 14 см убирает ткань рядом с прибором** (`cabin_geom.hh:128-129`). Расчёт аудитора: для гамма-поля, созданного в самом слое, доля, теряемая пустым каналом радиуса R, ≈ μ·⟨R/sinθ⟩ = μ·(π/2)·R; при μ(2 МэВ)/ρ ≈ 0,049 см²/г (значение NIST XCOM по памяти, в этой сессии не сверял), ρ 0,11 → ≈ 12 % для локально рождённых МэВ-фотонов (K-40 1461 кэВ, захват H 2,2 МэВ), меньше для более мягких. Эффект: занижение локальной компоненты на порядок 10 %.
10. **[НЕТ] Возврат частиц из салона на прибор (альбедо тела, столешницы)** — допущение 5 CFG-1; полностью не учтено; вклад — не нашёл.
11. **[НЕВЕРНО] Воздух: во всём мире (включая салон над слоем людей) ρ = 0,364 мг/см³**, тогда как салон 0,90 (`cabin_geom.hh:35-36,51-52,93`; комментарий на строке 35 это признаёт). Расчёт аудитора: до ~1 м воздуха × Δρ 0,54 мг/см³ ≈ 0,05 г/см²; при μ/ρ(воздух, 20 кэВ) ≈ 0,78 см²/г (NIST XCOM по памяти) ≈ 4 % по пропусканию — только у самого края диапазона.
12. **[ПРОВЕРИТЬ] Масса каркаса и пола — оценки ±30 %** (`cabin_geom.hh:25,29`; CFG-1 п. 8). Определяет прохождение 20–100 кэВ и e⁻; чувствительность не измерена.
13. **[ЛИШНЕЕ/упрощение] Порог 1 мм на этапе I** (`cabin_stage1.cc:234`) вместо 0,05 мм; в слое ρ 0,11 это эквивалентно заметно более высокой энергии обрезки δ-электронов и тормозных фотонов. Отступление от #CFG-2 признано в CFG-1 п. 3 и оценено там только для Al; для слоя людей числа не нашёл.
14. **[ПРОВЕРИТЬ] Данные HP для Ar-36, Ar-38 отсутствуют** — подставлены файлы Ar-37, Ar-39 (лог `results/stage1/prod2/neutron_0.psp.log:31-36`). Аргон воздуха 0,93 %; вклад — не нашёл.
15. **[ЛИШНЕЕ/приближение] Тепловое рассеяние: H в тканях = «H in water», H в пластике/ПЭТ/целлюлозе = «H in polyethylene»** (`cabin_geom.hh:54-55`, комментарий признаёт). Влияние на тепловую группу — не нашёл.

16. **[НЕВЕРНО] Эмиттер захвата теряет энергию конверсии.** `Cascade::conv_keV` накапливается (`capture_emitter.hh:263`), но `capture_step.hh` его не использует; при этом штатные вторичные (в т.ч. конверсионные электроны и рентген) удалены (`capture_step.hh:74-83`, добавляются только γ, строка ~103). ## 4. Что проверено и сходится (для полноты)
