### 1.3. Что делает `getHPcpp` (`subroutines.cpp:1387-1484`)

Порядок логики:

1. `ifirst==0` → однократно читает `input/FFPtable.day` в `FFP[год][мес][день]` и `input/FFPtable.uso` в `FFPuso[год]` (строки 1412–1439).
2. Проверка диапазона года 1614…2100 → иначе печать `"Out of period"`, `return 0.0` (1442–1447).
3. Проверка месяца/дня → иначе `"No such day"`, `return 0.0` (1448–1453).
4. Если `FFP[y][m][d] > -99.0` — данные есть: значение > 1000 трактуется как GLE и уменьшается на 10000; иначе возвращается как есть (1456–1469).
5. Иначе, если `FFPuso[y] != 0.0` — возвращается годовое значение Усоскина (1471–1477).
6. Иначе: **`ic=4; getHP=0.0; cout << "No FFP data is available"; return 0.0;`** (1479–1483).

**Уточнение к постановке задачи:** для 13.09.2026 срабатывает ветка 6 — `FFP[2026][9][13] = -100.0` (не проходит `> -99.0`), `FFPuso[2026] = 0.0` (таблица .uso кончается 2006 г.). Возврат — **0.0, но не молча**: в `stdout` печатается строка `No FFP data is available`. Ни исключения, ни ненулевого кода возврата нет, так что в пакетном прогоне сообщение легко теряется, а W = 0 уходит в расчёт как нормальное значение. Далее `main.cpp:119` кладёт это в `s`, и `getSpecCpp(ip,s,r,d,e,g)` (`main.cpp:135`) считает по нему спектр.

## 2. Как W-index считается по первоисточнику

Источник: T. Sato, «Analytical Model for Estimating Terrestrial Cosmic Ray Fluxes Nearly Anytime and Anywhere in the World: Extension of PARMA/EXPACS», PLOS ONE 10(12): e0144679 (2015) — https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0144679 (эта же ссылка указана в `parma/Readme.txt:8`).

| Что | Формулировка | Где |
|---|---|---|
| Природа W | параметр солнечной модуляции модели Matthiä, определяемый по счёту нейтронных мониторов | Sato 2015, раздел о W |
| Калибровка по монитору | **W_oulu = u₁·C_oulu + u₂**, где **u₁ = −0.093, u₂ = 638.7**, C — **отсчёты в минуту** | Sato 2015, ур. (22) и Табл. 2 |
| Станции калибровки | Oulu, McMurdo, Newark, South Pole, Thule, Climax | Sato 2015, Табл. 2 |
| Как строится суточный ряд | «The daily variation of W since 1951 was estimated by calculating the **mean value of W obtained from each station**» | Sato 2015 |
| До 1951 г. | по реконструкции интенсивности КЛ (Усоскин) — это и есть `FFPtable.uso` | Sato 2015; `subroutines.cpp:1471-1477` |
| GLE | дни GLE исключались из подгонки; «W values during GLE events cannot be precisely estimated using this method» | Sato 2015 |
| Связь с потенциалом силового поля | **V_M = 0.37 + 0.0003·W^1.45 [ГВ]** | Sato 2015; в коде — `getFFPfromW = 370.0 + 3.0e-1·pow(s,1.45)` МВ, `subroutines.cpp:25` |

Численные значения u₁,u₂ для McMurdo/Newark/South Pole/Thule/Climax из Табл. 2 машинным чтением страницы **извлечь не удалось** (таблица отдаётся изображением/вёрсткой, текст не распознан) — см. «что не подтверждено».

⚠ Ловушка единиц: NMDB отдаёт счёт Oulu в **отсчётах в секунду** (~100), формула Sato требует **отсчётов в минуту** (~6000). Множитель 60 обязателен.

### 4.4. Интервал

Складываются:
- измеренная ошибка экстраполяции: смещение −0.8, СКО 1.7, максимум 5.9 (§4.2);
- разброс между станциями: до 3.8 (§4.3);
- систематика: PARMA усредняет **шесть** станций, у нас доступны **две** — эта разница не измерена.

Рабочий интервал принят как **±6 единиц W** вокруг точки:
- 13.09.2026: **76**, интервал **70 … 82**;
- 14.09.2026: **73**, интервал **67 … 79**;
- на пару суток одним числом: **W = 75**, интервал **69 … 82**.

Насколько метод груб: в единицах потенциала силового поля весь интервал 69…82 — это 509…549 МВ, т. е. **±4 % по FFP**. Для сравнения, дефолтное W = 0 даёт 370 МВ — на 30 % ниже нижней границы интервала, это значение непригодно.

## 5. Что НЕ подтверждено

1. **Официального W на 13–14.09.2026 не существует.** Всё, что в разделе «ИТОГ», — наша оценка по счёту нейтронных мониторов, а не данные JAEA. При выходе EXPACS 4.20 число нужно заменить на опубликованное.
2. **Коэффициенты u₁, u₂ для McMurdo, Newark, South Pole, Thule, Climax не извлечены.** Табл. 2 статьи Sato 2015 машинным чтением страницы PLOS не распозналась; подтверждена только строка Oulu (−0.093; 638.7). Поэтому многостанционное усреднение по опубликованной методике воспроизвести не удалось — вместо него использована собственная регрессия по таблице PARMA.
3. **Доля вклада каждой станции в W из `FFPtable.day` неизвестна.** Sato пишет «mean value of W obtained from each station», но какие станции реально входили в ряд 2024–2026 (Climax закрыт в 2006, McMurdo — в 2017), из статьи не следует. Систематика «две станции вместо шести» не измерена.
4. **Ряд модуляционного потенциала Усоскина как основной путь применить нельзя.** Файл https://cosmicrays.oulu.fi/phi/Phi_mon.txt доведён только до **декабря 2025** (2025: 972 934 947 979 937 1095 975 924 979 960 1162 1077, годовое 995 МВ) — сентября 2026 в нём нет. Кроме того, его φ нормирован на другой ЛИС: для сентября 2025 он даёт 979 МВ, тогда как `getFFPfromWCpp` от табличного W(09.2025)=104.7 даёт 625 МВ. **Две величины не взаимозаменяемы**, подставлять φ Усоскина в PARMA вместо FFP нельзя.
5. **Чувствительность дозы на 11 км к выбранному W не измерена** — прогонов PARMA в рамках этой задачи не делалось (запрет на изменения/пересборку проекта). Приведён только пересчёт W → FFP по формуле модели.
6. **Отсутствие GLE 13–14.09.2026 установлено косвенно** — по гладкости почасового ряда Oulu, а не по записи в базе GLE (https://gle.oulu.fi/ — список событий машинным чтением не извлёкся).
7. **Ряды NMDB — «1 hour validated»**, для последних суток провайдер может выпустить уточнение. Данные за 13–19.09.2026 скачаны 20.09.2026 и при пересчёте могут слегка измениться.

## LESSONS

1. **Ожидал**, что для сентября 2026 придётся строить грубую двухточечную интерполяцию между двумя опорными датами (как и предполагала постановка). **Оказалось**, что таблица `FFPtable.day` сама по себе — готовая калибровочная выборка на ~4800 суток, к которой напрямую прикладывается ряд NMDB за тот же период. **Обход:** вместо интерполяции — регрессия по всей выборке плюс hold-out на последних 84 сутках, что даёт не оценочную, а **измеренную** ошибку метода (СКО 1.68, максимум 5.89).
2. **Ожидал**, что ряд модуляционного потенциала Усоскина (`cosmicrays.oulu.fi/phi/Phi_mon.txt`) будет основным путём, как и просила постановка. **Оказалось** двойное несовпадение: ряд кончается декабрём 2025, а его φ нормирован на другой ЛИС — для сентября 2025 он даёт 979 МВ против 625 МВ из формулы PARMA по её же табличному W. **Обход:** ряд Усоскина использован только как контекст, с явной пометкой о несопоставимости; основным стала калибровка по счёту мониторов.
3. **Ожидал** применить опубликованную формулу `W = −0.093·C + 638.7` к числам NMDB напрямую. **Оказалось**, что NMDB отдаёт Oulu в отсчётах в **секунду** (~100), а формула требует отсчётов в **минуту** (~6000) — без множителя 60 получается физически бессмысленное W ≈ 629. **Обход:** единицы проверены не рассуждением, а подстановкой в формулу двух опорных дат с известным из таблицы W (68.8 и 11.1): совпадение с точностью 0.5 и 1.1 подтвердило и множитель, и выбор ряда `corr_for_efficiency`.
