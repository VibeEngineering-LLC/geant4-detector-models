The file is concatenated after `stack.js`, which defines `buildStack(layers, i0, i1)` (returns array of `{id, contrib, lower, upper}` sorted ASCENDING by contribution, `lower`/`upper` are Float64Array) and `russianOrigin(label)` (returns a string). ## `yRange(arrays, j0, j1)`
`arrays`: array of numeric arrays. Return `{ymax, ymin}`: the maximum and the minimum over all values `> 0` of `arr[j]` for j from j0 to j1 inclusive (skip others). If there are no positive values return `{ymax: 0, ymin: Infinity}`.

## `drawStackLayers(ctx, st, o)`
Draw filled stacked layers on a canvas 2D context. `st` is the result of `buildStack`. `o` = `{j0, j1, E0, dE, X, Y, color}` where `X(E)` and `Y(v)` are functions converting energy and value to pixels, and `color(id)` returns a CSS colour string. For every layer of `st` in the given order: `ctx.fillStyle = o.color(l.id); ctx.globalAlpha = 0.9; ctx.beginPath();` move to and line along the points `(X(E0 + j*dE), Y(l.upper[j]))` for j from j0 to j1, then back along `(X(E0 + j*dE), Y(l.lower[j]))` for j from j1 down to j0, `ctx.closePath(); ctx.fill();`. After all layers set `ctx.globalAlpha = 1`.

## `legendRows(series, st, o)`
Build the rows of a legend sorted by contribution DESCENDING. `series`: array of `{id, label, group}`; `st`: result of `buildStack` (ascending); `o` = `{dE, hidden, colorOf, nameOf}`: `hidden` is an object id→true for hidden layers, `colorOf(id)` and `nameOf(s)` are functions (`nameOf` gets the series object and returns the display name). Let `sum` be the sum of `contrib` over `st` (use 1 if it is 0). Return an array (descending by contrib) of `{id, name, color, counts, share, on}` where `name = nameOf(series object with this id)`, `color = colorOf(id)`, `counts = contrib * dE` (number), `share = 100 * contrib / sum` (number), `on = !hidden[id]`. If the series object of a layer is not found skip that layer.

## `legendHtml(rows, totalOn, totalColor)`
Return an HTML string. First a block `<div class="series-group">` with one row for the whole spectrum: `<label class="series-row"><span class="color-swatch" style="background:COLOR"></span><input type="checkbox" data-id="total" CHECKED> Полный спектр (сумма слоёв)</label>` where `CHECKED` is the word `checked` if `totalOn` is true and empty otherwise; close the div. Then a block `<div class="series-group"><h3>Слои по убыванию вклада в показанном диапазоне</h3>` with one row per element of `rows`: `<label class="series-row"><span class="color-swatch" style="background:COLOR"></span><input type="checkbox" data-id="ID" CHECKED> NAME — COUNTS отсч./ч, SHARE %</label><br>`, with `COUNTS` = `Math.round(counts)` and `SHARE` = `share.toFixed(1)` (decimal point replaced by a comma). All text values `ID` and `NAME` must be HTML-escaped (`&`, `<`, `>`, `"`). Close the div.
