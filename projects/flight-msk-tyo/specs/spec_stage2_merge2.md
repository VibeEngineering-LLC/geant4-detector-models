Write ONE Python 3 script `stage2_merge.py` that imports the module `stage2_io` (same directory; use `sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))`) with these functions: `read_meta(path) -> dict[str,str]`, `read_total(path) -> ndarray (rows, 4)` with columns [sumw, sumw2, light_sumw, light_sumw2] (rates in s^-1 and squared uncertainties in s^-2), `write_total(path, arr, note)`, `read_cat(path) -> {(pg,proc,vol): {"names": (pgname, procname, volname), "bins": ndarray}}`, `write_cat(path, cats)`. Output ONLY the code (no markdown fences, no prose). Comments in Russian, short. Imports: `import sys, os, glob, tempfile`, `import numpy as np`, `sys.stdout.reconfigure(encoding="utf-8")`.

## Purpose
Merge the outputs of many simulation processes: files `<dir>/<base>_meta.txt`, `<base>_total.csv`, `<base>_cat.csv`, where `<base>` = `<component>_<k>` (component = `base.rsplit("_", 1)[0]`). Each file is a rate (per second) for ITS OWN simulated time `T_f` = `float(meta["T_sim_s"])`.

## Merging rules (exact)
For one component with files f and `T = sum T_f`: rates (columns 0 and 2 of the total array, and every category bin array) = `sum_f rate_f * T_f / T`; variances (columns 1 and 3) = `sum_f var_f * T_f**2 / T**2`. Total over components = plain sum of the component arrays (rates and variances both add). A category missing in a file counts as zero in that file (all bin arrays of one run have the same length).

## Functions
* `merge_component(items)`: `items` = list of dicts `{"T": float, "total": ndarray, "cats": dict}`; returns `(T, total_array, cats_dict)` with the rules above; `total_array` has the same shape as the inputs; `cats_dict` has the structure of `read_cat` (names from the first occurrence).
* `merge_dir(directory, out_prefix, nbin_expected=None)`: find all `*_meta.txt`; for each base read meta, total and cat; skip (message on stderr) a base with a missing file, `T_sim_s <= 0`, or — if `nbin_expected` is not None — with a total array whose number of rows is not `nbin_expected + 1`; group by component; call `merge_component`; write `<out_prefix>_total_<comp>.csv` for every component (`write_total(path, arr, "rates per second, merged T_sim_s=<T>")`), `<out_prefix>_total_all.csv` (component sum), `<out_prefix>_cat_all.csv` (union of the categories, bins summed over components, `write_cat`). Print a table to stdout: `component  files  T_sim_s  rate_sum_s^-1  stat_err_s^-1` (rate_sum = sum of column 0 over all rows except the last one (overflow); stat_err = sqrt(sum of column 1 over the same rows)), one line per component and one for `ALL` (files = total number). If nothing was merged, `sys.exit(2)`. Return the dict `{component: (T, total_array, cats)}` plus the key `"ALL"` for the total (its T is the sum over components, informational).
